# ZarinEngine Wiki

Wiki engine: MkDocs.

Run locally:

```bash
pip install -r requirements-wiki.txt
mkdocs serve
```

Build static site:

```bash
mkdocs build
```

Structure: docs/en/ English placeholders, docs/ru/ Russian placeholders, nav in mkdocs.yml.

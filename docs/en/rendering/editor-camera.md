# Editor Camera

The scene-editing camera. Never part of the build; it only drives editor viewports with orbit, pan and fly controls.

| Inspector field | Default | Meaning |
|---|---|---|
| Move Speed | 5 | Fly/orbit translation rate |
| Rotate Speed | — | Yaw/pitch rate |
| Zoom Speed | — | Dolly rate |
| Pan Speed | — | Screen-plane pan rate |
| Damping | — | Motion smoothing |
| Acceleration | — | Speed ramp |

Controls: WASD/QE fly, right/middle mouse drags, Alt+LMB orbit, fast mode ×3.

Related: Camera (runtime views), Viewport page of the Editor Manual.

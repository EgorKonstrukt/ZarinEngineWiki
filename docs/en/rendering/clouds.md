# Clouds

Volumetric-style cloud layer: coverage, density, wind drift, lighting response.

| Inspector group / field | Meaning |
|---|---|
| Cloud: Cloud Material | Shading material (`Clouds` / `CloudLayer` shaders) |
| Coverage / Density | Sky fill and thickness |
| Wind Speed / Wind Direction | Drift |
| Height / Thickness / Noise Scale | Layer geometry |
| Opacity / Shadow Strength | Look and sun blocking |
| Fog Density / Height Falloff / Scattering | Atmospheric blend |

Pairs with Procedural Sky or Skybox backgrounds; shadowed clouds darken the scene consistently with the sun position.

Related: Procedural Sky, Skybox, Atmosphere.

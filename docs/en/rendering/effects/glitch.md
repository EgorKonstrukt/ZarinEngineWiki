# Glitch

Per-object effect through the ObjectFx pass (unlike PostFX, which processes the whole frame). Built on the shared ObjectEffect base; scripts drive it by animating progress/intensity floats.

## How it works

Per-object vertex and UV jitter bursts, independent of the fullscreen Glitch post effect.

## Parameters

Burst amount, timing, axis bias.

## Tips

Malfunctioning robots, unstable holograms, cursed artifacts.

## Cost

Cheap.

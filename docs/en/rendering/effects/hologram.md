# Hologram

Per-object effect through the ObjectFx pass (unlike PostFX, which processes the whole frame). Built on the shared ObjectEffect base; scripts drive it by animating progress/intensity floats.

## How it works

Scanline projection look with transparency, flicker and height fade.

## Parameters

Scan density, flicker, alpha, height fade.

## Tips

Briefings, ghosts, minimap tables. Flicker harder when the projector is damaged.

## Cost

Cheap, transparent-sorted.

# Skybox

Static HDRI environment background with image-based lighting contribution.

| Inspector group / field | Meaning |
|---|---|
| HDRI Skybox: HDRI / EXR | Environment image |
| HDRI Skybox: Show Background | Draw the image as the sky |
| HDRI Skybox: Affect Environment (IBL) | Light PBR materials from the image |
| Image / Exposure (EV) / Intensity / Tint / Saturation | Look controls |
| Background Blur | Soften the visible sky |
| Flip Y, Orientation, Rotation Yaw/Pitch/Roll | Mapping controls |

Use Skybox for baked environments and Procedural Sky for dynamic day cycles. Match ambient values to the chosen sky.

Related: Procedural Sky, Clouds, Atmosphere, Directional Light (procedural coupling).

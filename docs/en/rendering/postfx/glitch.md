# Glitch

Part of the PostFX stack: runs after the main scene pass in component order. Built on the shared GraphicsEffect base with an enable toggle plus effect-specific Inspector fields.

## How it works

Digital corruption bursts: slice offsets, channel swaps, noise hits with timing controls.

## Parameters

Burst amount, slice count, blockiness, timing/trigger.

## Tips

Damage feedback, hacking minigames, malfunctioning holograms. Trigger from scripts on hit.

## Cost

Cheap at rest, medium during bursts.

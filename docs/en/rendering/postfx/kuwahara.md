# Kuwahara

Part of the PostFX stack: runs after the main scene pass in component order. Built on the shared GraphicsEffect base with an enable toggle plus effect-specific Inspector fields.

## How it works

Painterly region flattening that turns renders into oil-painting patches while keeping edges.

## Parameters

Patch radius, hardness.

## Tips

Stylized cutscenes and painterly exploration zones.

## Cost

High by radius. Use sparingly.

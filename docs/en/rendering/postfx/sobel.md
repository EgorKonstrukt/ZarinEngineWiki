# Sobel

Part of the PostFX stack: runs after the main scene pass in component order. Built on the shared GraphicsEffect base with an enable toggle plus effect-specific Inspector fields.

## How it works

Sobel-operator outlines for technical and blueprint rendering.

## Parameters

Threshold, line feel.

## Tips

Scanner vision, schematic modes, CAD previews with grid overlays.

Cheap.

# Lens Distortion

Part of the PostFX stack: runs after the main scene pass in component order. Built on the shared GraphicsEffect base with an enable toggle plus effect-specific Inspector fields.

## How it works

Barrel/pincushion warping with edge stretch for cheap optics character.

## Parameters

Amount, center, edge handling.

## Tips

Fisheye power-ups, drunk effects, retro camcorders.

## Cost

Cheap.

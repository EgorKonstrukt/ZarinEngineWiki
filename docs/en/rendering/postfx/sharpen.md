# Sharpen

Part of the PostFX stack: runs after the main scene pass in component order. Built on the shared GraphicsEffect base with an enable toggle plus effect-specific Inspector fields.

## How it works

Detail enhancement via unsharp-style filtering; halo ringing is the overdose symptom.

## Parameters

Amount, radius feel.

## Tips

Recovering FSR2/upscaled softness; product shots. Small values only.

## Cost

Cheap.

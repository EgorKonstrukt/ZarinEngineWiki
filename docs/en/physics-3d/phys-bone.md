# PhysBone

Bone-chain dynamics for hair, tails, capes, antennae and dangling props.

| Inspector group | Covers |
|---|---|
| Transforms | Root Transform, Ignore Transforms, Ignore Other Phys Bones, Endpoint Position, Multi Child Type |
| Forces | Integration Type, Pull (+Curve), Spring (+Curve), Damping (+Curve) and further force tuning |
| Limits / Colliders | Limit Type, Immobile handling, attached PhysBoneCollider set |

Curves over chain length allow stiff roots with floppy tips. Colliders deflect the chain; see PhysBoneCollider for shapes.

Related: PhysBoneCollider, Armature, Skinned Mesh Renderer, IK notes in Animation.

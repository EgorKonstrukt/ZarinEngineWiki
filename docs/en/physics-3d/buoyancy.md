# Buoyancy

Floating bodies for ponds, rivers and oceans.

| Inspector group / field | Meaning |
|---|---|
| Buoyancy: Object Density | Hull density vs water |
| Override Volume | Manual displaced volume |
| Water Density | Liquid density |
| Hydro Drag / Hydro Angular Drag | Water damping |
| Flow Influence | How much currents push |
| Options: Use Waves / Use Flow | Surface and current sampling |
| Sample Resolution | Probe density over the hull |
| Max Accel (x g) | Stability clamp |
| Debug Draw | Volume visualization |

Pair with a WaterVolume environment component marking the liquid region and a Water surface for visuals.

Related: Water, Soft Body, Rigidbody.

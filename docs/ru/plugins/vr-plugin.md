# VR-плагин

Поддержка виртуальной реальности редактора и рантайма в `plugins/vr_plugin/`: рантайм-ядро плюс док редактора.

- `vr_core.py` — управление сессией и девайсами: позы шлема кормят камеры сцены, контроллеры появляются как трекаемый ввод рядом со стандартным Input API для скриптов.
- `vr_dock.py` — панель редактора: старт/стоп VR-сессий, зеркало вида шлема во вьюпорт, статус девайсов и настройки на глаз.

Процесс: откройте VR-док, подключите шлем, стартуйте сессию — игровое окно рисует стереопару, а десктопный вьюпорт держит камеру редактора для постановки. Скрипты читают позы контроллеров через те же конвенции Transform/Input, что десктоп (девайсные биндинги всплывают кнопками и осями).

Поза по производительности: VR удваивает рендер (два глаза) — сначала пополам render_scale, затем разрешение теней, затем PostFX. Постадийные тайминги профайлера идут на глаз; бюджет 11 мс суммарно, а не на глаз.

Заметка скоупа: desktop-first движок с VR-пристройкой, а не VR-нативный: room-scale трекинг и guardian-потоки зависят от OpenVR/OpenXR-рантаймов на машине.

Диагностика: шлем не найден — не запущен рантайм (SteamVR/monado); чёрный глаз — переполнение resolution scale, опустите render_scale; дрейф — потеря трекинга в рантайме, рецентр там.

Связанное: камеры (источник стереопары), API ввода (биндинги контроллеров), профайлер, режимы разрешения.

# Музыка, плоттер и QtQuick

Меньшие bundled-расширения для звука, данных и хостинга UI — тот же базовый класс, те же хуки, уже работы.

Трекерная музыка (`plugins/tracker_music_plugin/`, движок `libs/nodmod`):

- Проигрывание модулей в стиле ProTracker (паттерны, сэмплы, темп от BPM) для ретро-скоров и демосцен-вайба.
- Бросьте файл модуля, ведите play/stop из хуков или скриптов, миксуйте под позиционные AudioSources — музbed плюс 3D-эффекты и есть intended стек.
- Математика темпа следует классическим трекерным конвенциям (тики на ряд против BPM).

Плоттер (`plugins/plotter_plugin/`):

- Панели графиков кривых/данных: трейсы профайлера, кривые анимации, телеметрия — числа картинками во время настройки.
- Кормите из хуков `step()` или лог-тапов; в пару с панелью профайлера для frame-time криминалистики.

QtQuick (`plugins/qt_quick_plugin/`):

- Хостит QtQuick/QML-поверхности внутри редактора: анимированные дашборды, кастомные tool-UI, панели в веб-стиле без борьбы с тулкитом.
- Для tooling-хрома; геймплейный UI остаётся в GUI-системе (виджеты GuiCanvas шипаются в сборках, QtQuick этого не гарантирует).

Все три итерируются как любой пользовательский плагин (тот же lifecycle, та же персистентность) и пакуются в `.zplugin` для шаринга.

Связанное: аудиосистема (пара музbed), профайлер (источник данных плоттера), обзор GUI (дом геймплейного UI), упаковка .zplugin.

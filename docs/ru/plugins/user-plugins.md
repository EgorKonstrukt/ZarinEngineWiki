# Гид пользовательских плагинов

Командные инструменты живут в `plugins/user/` `.py`-файлами: импортёры, уровневые утилиты, батч-переименования, экспериментальные риги, кастомные панели. Системный тир не тронут; пользовательский итерируется свободно.

Скаффолд по шагам:

1. Скопируйте `plugins/example_plugin.py` в `plugins/user/my_tool.py`.
2. Переименуйте класс и `NAME` (ключ менеджера — уникален на плагин), поднимите `VERSION`, напишите однострочный `DESCRIPTION`, оставьте `SYSTEM = False`.
3. Реализуйте `initialize(engine)`: пункты меню, кнопки тулбара, доки, открыватели файлов. Проектозависимую настройку отложите на `on_project_opened` — `initialize` идёт до известного корня проекта.
4. Добавьте хуки поведения: `step` для покадровых инструментов, `on_scene_loaded` для сканеров сцен, `on_play_start/stop` для сессионных ригов.
5. Persist через `get_config`/`set_config` — раскладки окон, последние пути, счётчики переживают рестарты с нулевым файловым кодом.
6. Перезапустите редактор (или рескан плагинов из панели менеджера) и проверьте: пункт меню, кнопка, строки консоли.

Этикет патчинга: расширяйте компоненты через `add_inspector_field` и `patch_component` вместо правок ядра — ваши поля едут на обновлениях движка, а не конфликтуют. Всё откатывается на shutdown автоматически.

Отладка: сначала консоль (ошибки импорта именуют модуль и строку), затем панель менеджера (состояние на плагин), затем `Logger.debug`-хлебные крошки. Плагин, упавший в `initialize`, скипается с логом — редактор стартует всегда.

Дистрибуция в команде: доверенным коллегам — прямо `.py`-файлом; всем остальным — `.zplugin` (подписан, версионирован, с проверкой зависимостей — см. упаковку).

Антипаттерны: блокирующие сетевые вызовы в `initialize` (отложите на хуки/потоки), дубли `NAME` в файлах (вторая загрузка меняет первую), абсолютные пути в конфигах (храните относительно проекта), покадровые аллокации в `step` (кэшируйте в `initialize`).

Связанное: разбор example-плагина (конвенции), жизненный цикл PluginBase (хуки), упаковка .zplugin (дистрибуция), панель менеджера плагинов (руководство по редактору).

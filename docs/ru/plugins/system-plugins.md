# Каталог системных плагинов

Поставляются в `plugins/` с `SYSTEM = True`: расширения уровня движка, грузятся первыми и остаются вкл. По странице двум сверенным; капсулы остальным (файлы сверены по именам, детали в их панелях).

| Плагин | Файл(ы) | Роль |
|---|---|---|
| Network Plugin | `network_plugin.py` | Геймплейная обвязка транспорта: host/connect, хендлеры, покадровый poll. См. страницу сетевого плагина. |
| Physics Plugin | `physics_plugin.py` | Режимы солвера (single/multi/per-layer), фоновый процесс, синк сцены. См. солвер и потоки. |
| Physics Drag Plugin | `physics_drag_plugin.py` | Таскание rigidbody мышью во вьюпорте редактора. |
| Physics Visualisation Plugin | `physics_visualisation_plugin.py` | Отладочная отрисовка форм и цветов слоёв. |
| Mesh Editor Plugin | `mesh_editor_plugin.py` | Внутриредакторное моделирование в стиле ProBuilder и операции. |
| VR Plugin | `vr_plugin/` (`vr_core.py`, `vr_dock.py`) | VR-рантайм ядро плюс док редактора. См. страницу VR. |
| MCP Bridge | `zarin_mcp/` (server, dock, registry, handlers) | MCP-сервер, выставляющий инструменты движка AI-агентам. См. страницу MCP. |
| Tracker Music Plugin | `tracker_music_plugin/` | Проигрывание трекерной музыки (движок nodmod) для ретро-скоров. |
| Plotter Plugin | `plotter_plugin/` | Панели графиков кривых/данных. |
| QtQuick Plugin | `qt_quick_plugin/` | Хостинг QtQuick-поверхностей внутри редактора. |

Системные регистрируют компоненты, доки и панели ровно как пользовательские (тот же базовый класс, те же хуки) — разница лишь в тире загрузки и опоре движка. Отключение физики или сети деградирует matching подсистему; панель менеджера предупреждает заранее.

`.pending/` держит staged плагины до активации; `mcp_pack-2.1.1.zplugin` — шиппабельный MCP-артефакт (см. упаковку).

Связанное: менеджер плагинов (тиры), сетевой плагин, VR-плагин, MCP-мост, страница музыка/плоттер/QtQuick.

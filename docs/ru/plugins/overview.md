# Обзор плагинов

Плагины расширяют редактор и движок без правок ядра: док-панели, кнопки тулбара, пункты меню, новые компоненты, открыватели файлов, патчи методов, дополнительные поля инспектора, нативные расширения.

Два вкуса:

- Системные (`SYSTEM = True`, живут в `plugins/`): физика, сетевой транспорт, меш-редактор, VR, MCP-мост — движок на них полагается, грузятся первыми, просто так не снимаются.
- Пользовательские (`SYSTEM = False`, живут в `plugins/user/`): командные инструменты, импортёры, уровневые утилиты, экспериментальные риги — после системных, вкл/выкл свободно.

Три формата, один менеджер:

- Исходники `.py` с фабрикой `get_plugin()`, возвращающей инстанс.
- Нативные `.dll` / `.so` с Python-шимом входа.
- Подписанные пакеты `.zplugin`: манифест + код + нативные модули + bundled-библиотеки, проверка по `config/trusted_keys`, распаковка один раз с кэшем по sha256-отпечатку.

`PluginManager` (`core/foundation/plugin_manager.py`, ~1700 строк) владеет discovery, `_load_order`, активацией, проверкой зависимостей из манифестов, security-верификацией, персистентностью конфигов и разборкой в обратном порядке.

Страницы: жизненный цикл PluginBase, менеджер плагинов, разбор example-плагина, гид пользовательских, упаковка .zplugin, каталог системных, сетевой плагин, VR-плагин, MCP-мост, расширения музыка/плоттер/QtQuick.

Первый плагин за пять минут: скопируйте `plugins/example_plugin.py` в `plugins/user/my_plugin.py`, переименуйте класс и `NAME`, оставьте `get_plugin()` внизу, перезапустите редактор — пункт меню появится, кнопка тулбара появится, счётчик запусков переживёт сессии.

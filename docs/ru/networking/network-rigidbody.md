# NetworkRigidbody

Синк физического состояния: скорости едут рядом с трансформами, и ремоуты экстраполируют вместо догона.

| Группа / поле инспектора | Смысл |
|---|---|
| Sync: Sync Velocity / Sync Angular | Тоглы каналов скоростей |
| Network Rigidbody: Authority | RigidbodyAuthority — обычно симулирующий пир или хост |
| Send Rate | Обновлений в секунду |
| Vel Threshold | Минимальное изменение скорости ради отправки |
| Interpolate / Interp Delay | Удалённое сглаживание, близнец настроек трансформа |

Читается в `on_fixed_update` (часы физики), пишется визуально в `on_update` — синк повторяет сплит симуляции, без полушаговых разрывов.

Правило паринга: всегда рядом с NetworkTransform на динамических телах. Один трансформ заставляет ремоутов догонять позиционными правками (плавающий вид); скорости дают баллистическое скольжение между снапшотами — разница между играбельно и пьяным вождением.

Поза авторитетности: owner-simulated (водитель владеет машиной, хост доверяет) для отзывчивости; host-simulated для соревновательной честности (хост интегрирует, все рисуют). Пороги прячут idle-дрожание; teleport трансформа закрывает респавны.

Диагностика: орбитящие ремоуты — скорость без позиции, парьте оба; взрывы энергии на догоне — мал interp delay, поднимайте; хост/клиент спорят о стопках — только один авторитет, никогда два писателя.

Связанное: NetworkTransform (позиционный близнец), Rigidbody (локальный API), NetworkIdentity (источник authority), солвер и потоки (источник fixed-шага).

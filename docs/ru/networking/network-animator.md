# NetworkAnimator

Синк состояния анимации: какой клип, на каком времени, скорость и флаг проигрывания — плюс геймплейные параметры.

| Группа / поле инспектора | Смысл |
|---|---|
| Sync: Sync Clip / Time / Speed / Playing | Канальные тоглы — idle-циклам достаточно клипа |
| Network Animator: Authority | AnimatorAuthority |
| Send Rate | Обновлений в секунду |
| Sync Params | Именованный набор параметров (bool, float, триггеры снапшотом) |

API: `apply_snapshot(data)` — удалённая запись; `trigger(name)`, `set_float(name, value)`, `set_bool(name, value)` — локальные вызовы с репликацией ремоутам.

Мудрость полосы: клип + playing на низком rate для ambient-персонажей; время добавляйте только где важен foot-sync (танцы, марш); параметры несут геймплейную правду (aim-бленды, hurt-флаги), имена клипов — визуал. Триггеры fire-and-forget — снапшот несёт их раз, так что триггерьте в тик отправки или форсите отправку.

Заметка файтингам: time-синк на полном rate дорог; предпочитайте детерминированное проигрывание (один старт + общие часы), синкайте только триггеры и параметры.

Диагностика: T-поза на ремоутах — mismatch имён клипов (разные имена ассетов по сборкам); рассинхрон танца — выкл канал времени; залипший триггер — ушёл между тиками без снапшота, форсите на триггере.

Связанное: NetworkIdentity, клипы и Animator, NetworkVariables (близнец параметров).

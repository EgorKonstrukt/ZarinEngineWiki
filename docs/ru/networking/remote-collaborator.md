# RemoteCollaborator

Внутриредакторный стенд-ин удалённого пира: куда смотрит, что держит выделенным, что тащит.

Компонент на 46 строк (`core/components/network/remote_collaborator.py`) без кастомных `_inspector_fields` — присутствие и есть данные (идентичность в `peer_id` / `peer_name` / `color`, персистентность через `serialize`/`deserialize`). Рисует `gizmo_lines` / `gizmo_meshes` каждый кадр: квадрат-маркер со стержнем на трансформе пира в цвете пира (`gizmo_meshes` возвращает `[]`).

Пиры появляются при коннекте коллаборации и исчезают по таймауту дисконнекта; маппингом id пира на сущность владеет CollaborationManager. Цвета стабильны на пира в сессии — команды выучивают кто есть кто.

Использование в ко-редактировании: следуйте за фрустумом, видя постановку партнёра; не хватайте его выделенное поддерево; смотрите его гизмо-драг до приземления, ловя ошибки рано.

Диагностика: пира нет — не подключён или таймаут; несвежая поза — встал op-stream, проверьте задержку; не тот цвет — переподключение, цвета переназначились.

Связанное: коллаборация (сессии), NetworkPlayer (геймплейный близнец данных пиров), гизмо и иконки (проходы рендеринга).

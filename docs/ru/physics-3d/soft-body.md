# Soft Body

Симуляция деформируемого меша для ткани, желе и мнущегося реквизита.

| Группа / поле инспектора | Смысл |
|---|---|
| Soft Body: Mass / Stiffness | Вес против жёсткости |
| Bend Mode | Модель отклика на изгиб |
| Pressure | Надувание замкнутых мешей |
| Damping / Iterations | Успокоение и качество солвера |
| Gravity Scale | Локальный множитель гравитации |
| Vertex Radius | Толщина коллизий на вершину |
| Max Velocity | Клапм стабильности |
| Pin Mode / Pin Fraction | Доля пришитых вершин |
| Max Vertices | Бюджет симуляции |
| Double Sided | Двусторонние коллизии |

Вершины, центр масс и скорости обмениваются с солвером через soft-буфер каждый шаг — тяжелее rigid-тел, бюджетируйте вершины.

Связанное: плавучесть, PhysBone, тканевые эффекты объектов.

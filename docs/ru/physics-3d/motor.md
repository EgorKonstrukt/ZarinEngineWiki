# Мотор Motor

Постоянный привод для конвейеров, колёс, вентиляторов, ловушек-вертушек, лифтов и серво-дверей — steady движение без скриптованной скорости каждый кадр.

| Группа / поле инспектора | Смысл |
|---|---|
| Connected Entity | Ссылка на ведомое тело |
| Motor Type | Вращательный или поступательный привод |
| Mode | Скоростной круиз или позиционный сервопривод |
| Axis / Anchor | Направление привода и пивот |
| Drive: Target Velocity | Крейсерская скорость |
| Drive: Motor Force / Motor Torque | Капы усилия (поведение stall) |
| Limits: Limit Low / Limit High | Границы хода для серво-режима |
| Free Spin | Полностью игнорировать лимиты |

Гид режимов: скоростной с большой силой — конвейер или вентилятор (никогда не глохнет); позиционный с лимитами — серво-дверь или лифт (доезжает до границы и держит); free-spin колёса игнорируют лимиты и идут на целевой скорости.

Капы силы определяют stall: кап ниже нагрузки глохнет под весом — верно для гаражных ворот с ящиками; бесконечный кап прёт сквозь всё — верно для давилок.

Паттерны: конвейер — скоростной мотор по оси ленты на kinematic-теле; разводной мост — позиционный серво с лимитами 0…π/2; мельница — free-spin вращение со скромным моментом; давилка — поступательный серво с большой силой и медленной скоростью.

Диагностика: не едет — потеряна connected entity или разорвана kinematic-цепь; проскакивает границы — велика сила для серво, опустите кап или поднимите демпфирование через джойнт; дрожь на границе — борьба лимита, расширьте мёртвую зону.

Связанное: джойнты (пассивные связи), Rigidbody (ведомые тела), CharacterController (едущие платформы).

# Мотор Motor

Постоянный привод для конвейеров, колёс, вентиляторов и ловушек-вертушек.

| Группа / поле инспектора | Смысл |
|---|---|
| Connected Entity | Ссылка на ведомое тело |
| Motor Type | Вращательный или поступательный привод |
| Mode | Скоростной или позиционный сервопривод |
| Axis / Anchor | Направление привода и пивот |
| Drive: Target Velocity | Крейсерская скорость |
| Drive: Motor Force / Motor Torque | Капы усилия |
| Limits: Limit Low / Limit High | Границы хода |
| Free Spin | Игнорировать лимиты |

Скоростной мотор с большой силой — конвейер; позиционный с лимитами — серво-дверь.

Связанное: джойнты, Rigidbody, CharacterController (платформы под игроком).

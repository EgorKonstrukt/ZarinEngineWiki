# Слои коллизий

Кто с кем сталкивается. Каждый коллайдер несёт `layer` (по умолчанию 0) и `mask` (по умолчанию `0xFFFF`, столкновения со всеми); пара должна совпасть с обеих сторон для контакта.

Логика фильтрации живёт в `core/physics/collision_layers.py`. Режим `per_layer_process` дополнительно изолирует слои в процессы солвера по требованию.

Паттерны: отдельные слои мира, игрока, врагов и снарядов; мьют enemy-vs-enemy ради экономии солвера; односторонние платформы — слоем, выведенным из маски игрока снизу через триггеры.

Связанное: физические материалы, солвер и многопоточность, все страницы коллайдеров.

# Слои коллизий

Кто с кем сталкивается, независимо от реакции поверхности. Каждый коллайдер несёт `layer` (по умолчанию 0) и `mask` (по умолчанию `0xFFFF`, столкновения со всеми); контакт требует взаимного согласия сторон.

Логика фильтрации в `core/physics/collision_layers.py`. Режим `per_layer_process` дополнительно изолирует слои в процессы солвера по требованию для полностью независимых суб-симуляций.

План слоёв типового экшена:

- 0 World — статичная геометрия, сталкивается со всем геймплейным.
- 1 Player — персонаж и его хитбоксы.
- 2 Enemy — боты; мьют enemy-vs-enemy экономит солвер на толпах.
- 3 Projectile — выстрелы; маска на мир + персонажей, никогда на подборы.
- 4 Pickup — только триггеры, маска на игрока.
- 5 Sensor — триггеры зрения/слуха AI, маска на игрока + врагов, без физического отклика.

Триггеры (`is_trigger`) сообщают пересечения через тот же тест масок без контактного отклика — сенсор не на том слое молчит, а не сломан.

Односторонние платформы: коллайдер платформы на слое, выведенном из маски игрока, плюс тонкий верхний триггер, включающий коллизию при перекрытии сверху — скриптуется в пару строк на `on_collision_enter/exit`.

Отладка: включите визуализацию физики (плагин) с раскраской тел по слоям; молчаливые пары почти всегда mismatch масок, а не отсутствующие компоненты.

Связанное: физические материалы, солвер и потоки (per-layer режим), все страницы коллайдеров, джойнты (связанным телам нужна сталкивающаяся пара).

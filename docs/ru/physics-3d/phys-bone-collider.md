# PhysBoneCollider

Отражатели, держащие цепочки PhysBone вне тел: волосы — из головы, плащ — из ног, хвосты — из стен.

| Группа / поле инспектора | Смысл |
|---|---|
| Shape: Shape Type | Объём sphere, capsule или plane |
| Radius / Height / Center | Размеры формы в локале |
| Direction / Plane Normal | Ориентация капсул и плоскостей |
| Behavior: Inside Bounds | Как резолвится глубокое проникновение (вытолкнуть vs скользить) |
| Gizmos: Show Gizmo | Визуализация объёма во вьюпорте |

Вешается на часть тела, которой цепочка избегает, размером чуть больше визуального меша — цепочки симулируются на костях внутри меша, и skin-tight коллайдеры всё равно клиппят. В рантайме цепочка скользит вокруг объёма вместо прохода.

Паттерны: сфера головы + капсула торса для длинных волос; капсулы бёдер для пальто; плоскость пола для ползающих; inside-bounds для серёг у уха.

Держите число коллайдеров на цепочку малым (1–3): каждый тестирует каждую частицу цепочки каждый шаг.

Диагностика: всё равно клиппит — коллайдер меньше offset костей, растите; цепочку выталкивает целиком — коллайдер поглотил корень, двигайте вниз по цепи; дрожь на контакте — inside-bounds дерётся с лимитом, смените поведение.

Связанное: PhysBone, арматура, Sphere/Capsule-коллайдеры (статичные аналоги мира).

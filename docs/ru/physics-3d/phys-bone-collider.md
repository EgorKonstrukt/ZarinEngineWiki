# PhysBoneCollider

Отражатели для цепочек PhysBone: волосы — из головы, плащ — из ног.

| Группа / поле инспектора | Смысл |
|---|---|
| Shape: Shape Type | Сфера, капсула, плоскость |
| Radius / Height / Center | Размеры формы |
| Direction / Plane Normal | Ориентация |
| Behavior: Inside Bounds | Как резолвится глубокое проникновение |
| Gizmos: Show Gizmo | Визуализация объёма |

Вешается на часть тела, которой цепочка должна избегать; в рантайме цепочка скользит вокруг объёма.

Связанное: PhysBone, арматура, Sphere/Capsule-коллайдеры.

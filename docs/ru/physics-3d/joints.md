# Джойнты

Соединяют два тела связью. Поля:

| Поле | Default | Смысл |
|---|---|---|
| `connected_entity_name` | — | Имя другой сущности |
| `anchor` | начало | Пивот в локальных координатах |
| `axis` | (0,0,1) | Ось hinge/spring |
| `joint_type` | hinge | `HINGE`, `FIXED` или `SPRING` |
| `limit_low` | −π | Нижний угловой лимит, радианы |
| `limit_high` | +π | Верхний угловой лимит, радианы |
| `stiffness` | 10.0 | Жёсткость пружины |
| `damping` | 1.0 | Демпфирование пружины |

Hinge — двери и колёса (лимитами лочится ось), fixed — ломаемые крепления, spring — подвеска и желе. У связанной сущности должны быть свои `Rigidbody` + коллайдер; оба тела должны зарегистрироваться до резолва джойнта, поэтому создавайте пару до Play или в порядке `on_awake`.

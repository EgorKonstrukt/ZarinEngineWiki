# Capsule-коллайдер

Тела персонажей и пилюли: цилиндр со сферическими крышками, не цепляющийся за швы пола как боксы и стабильный при вращении в отличие от сырых цилиндров.

| Группа / поле инспектора | Default | Смысл |
|---|---|---|
| Collision: Layer / Collision Mask | 0 / 0xFFFF | Фильтрация |
| Shape: Center | начало | Локальный сдвиг |
| Shape: Radius | 0.5 | Масштабируется наибольшей осью |
| Shape: Height | 2.0 | Полная высота, масштабируется по оси направления |
| Shape: Direction | 1 (Y) | 0 = X, 1 = Y, 2 = Z |
| Is Trigger | выкл | События пересечения без контактного отклика |
| Material: Physic Material | — | Оверрайд ассетом `.zphysmat` |

При дефолтах совпадает с капсулой CharacterController (0.5/2.0) — те же числа для AI-тел, и игроки с ботами сталкиваются идентично.

Гид ориентации: Y для стоячих, X/Z для лежачих и катящихся (брёвна, бочки на боку). Высота включает крышки; высота ниже `radius * 2` вырождается к сфере — солвер клампит, но гизмо показывает правду.

Враги с выпадами и дэшами стоят прямо заморозкой осей Rigidbody при той же капсуле — наклоняются без опрокидывания.

Диагностика: цепляется за ступени — велик радиус под глубину проступи или мала высота шага (контроллера); парит над землёй — offset центра поднял крышки; вертится бревном — заморозьте оси поворота.

Связанное: CharacterController, Sphere-коллайдер, Rigidbody.

# Контроллер персонажа

Кинематическое тело для first/third-person, ведётся move-функцией солвера, а не силами.

Скорости по умолчанию: ходьба 260, бег 440 (Shift), крадучись 130, ускорение 10, ускорение в воздухе 10, трение 4, скорость остановки 80.

Прыжок и гравитация: сила прыжка 300, буфер прыжка 0.1 с, coyote time 0.1 с (прыжок работает, пока живы оба таймера: `velocity.y = jump_power`), гравитация 800.

Форма: радиус капсулы 0.5, высота 2.0 (итог минимум `radius * 2 + 0.1`), высота крадучись 1.2, высота шага 0.3, макс. склон 45°, сила толкания 30.

Каждый фиксированный шаг контроллер: проверяет землю, ускоряется с трением на земле, применяет гравитацию в воздухе, вызывает `move_character` солвера с желаемой скоростью, затем пишет результирующую позицию обратно в трансформ и применяет yaw-поворот.

Требование: нужен солвер в процессе (читает состояние мира напрямую). В фоновых режимах движок откатывается на однопоточную физику с предупреждением в консоли.

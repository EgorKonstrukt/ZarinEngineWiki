# Твёрдое тело Rigidbody

Делает сущность симулируемой: масса, реакция на гравитацию, накопление сил, читаемые скорости.

Поля инспектора:

| Поле | Default | Смысл |
|---|---|---|
| `mass` | 1.0 | Масса тела; при kinematic форсируется в 0 |
| `drag` | 0.0 | Линейное затухание |
| `angular_drag` | 0.05 | Угловое затухание |
| `use_gravity` | True | Гравитация действует |
| `is_kinematic` | False | Ведётся трансформом, толкает других, но не толкается |

Плюс поосевые тоглы заморозки позиции и поворота, сериализуются как тройки `freeze_pos` / `freeze_rot`.

API из скриптов:

```python
rb = self._entity.get_component_by_name("Rigidbody")
if rb:
    rb.add_force(Vec3(0.0, 10.0, 0.0))
    rb.add_torque(Vec3(0.0, 1.0, 0.0))
    rb.add_impulse(Vec3(0.0, 5.0, 0.0))
    v = rb.velocity
```

- `velocity` / `angular_velocity` — читаются каждый кадр, запись помечает тело грязным, и значение уходит в солвер.
- `add_force` / `add_torque` — копятся до следующего шага, затем сбрасываются.
- `add_impulse` — мгновенное изменение скорости `impulse / mass`; игнорируется для кинематики и неположительной массы.

Правило сборки: динамическое тело = `Rigidbody` (положительная масса, не kinematic) плюс коллайдер. Один коллайдер — статичная декорация. Создание тела читает `mass` и `is_kinematic`; скорости и силы синхронизируются каждый шаг.

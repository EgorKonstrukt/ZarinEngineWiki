# Твёрдое тело Rigidbody

Делает сущность симулируемой: масса, реакция на гравитацию, накопление сил, читаемые скорости. Без него коллайдер — статичные декорации; с ним сущность вступает в мир динамики.

Поля инспектора:

| Поле | Default | Диапазон | Смысл |
|---|---|---|---|
| mass | 1.0 | 0.001–100000 | Масса; при kinematic форсируется в 0 |
| drag | 0.0 | 0–1000 | Линейное затухание (воздух, вода) |
| angular_drag | 0.05 | 0–1000 | Затухание вращения |
| use_gravity | вкл | — | Гравитация действует |
| is_kinematic | выкл | — | Ведётся трансформом: толкает динамику, не толкается |

Плюс поосевые тоглы заморозки позиции и поворота, сериализуются тройками `freeze_pos` / `freeze_rot` в `.zpes`.

API из скриптов, сверено:

```python
rb = self._entity.get_component_by_name("Rigidbody")
if rb:
    rb.add_force(Vec3(0.0, 10.0, 0.0))
    rb.add_torque(Vec3(0.0, 1.0, 0.0))
    rb.add_impulse(Vec3(0.0, 5.0, 0.0))
    v = rb.velocity
```

- `velocity` / `angular_velocity` — читаются каждый кадр, запись помечает тело грязным, и значение уходит в солвер на следующем синке.
- `add_force(force, world_space=True)` / `add_torque(torque)` — копятся до следующего шага, затем автосбрасываются.
- `add_impulse(impulse)` — мгновенное изменение скорости `impulse / mass`; игнорируется для кинематики и неположительной массы.
- `consume_velocity_dirty()` / `_clear_forces()` — внутренний протокол синка; геймплей их почти не дёргает.

Механика: создание тела читает `mass` и `is_kinematic` (кинематика форсирует массу 0); скорости и силы синкаются каждый шаг. Флаги заморозки лочат оси на стороне солвера — замороженная Y-позиция плюс гравитация даёт скользящую шайбу; замороженные повороты — неопрокидываемые ящики.

Гид масс: игрок 70–90, ящики 1–10, мебель 20–50, техника 500–2000. Отношения beyond ~100:1 между контактирующими телами напрягают любой солвер — держите геймплейные контакты в двух порядках.

Диагностика: проваливается сквозь пол — нет коллайдера, оба триггеры или туннелирование на скорости (уменьшите fixed dt или кап скорости); игнорирует силы — вкл kinematic или масса 0; дрейфует вечно — нулевые drag и трение, поднимите оба; дрожь в стопках — мало итераций солвера или экстремальное отношение масс.

Связанное: все страницы коллайдеров, CharacterController (kinematic-альтернатива), джойнты, солвер и потоки, примеры скриптов (Kicker).

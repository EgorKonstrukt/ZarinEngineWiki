# Обзор физики 3D

Встроенный 3D-солвер работает вне главного потока: симуляция шагает в фоновом воркере, пока поток ECS рисует, выполняет скрипты и синхронизирует трансформы каждый кадр.

Конвейер фиксированного шага:

1. Регистрация новых сущностей и периодическая перепроверка шейпов.
2. Синхронизация ECS → физика (телепорт грязных трансформов, иначе накопленные силы/моменты и грязные скорости).
3. Шаг солвера с `dt` (по умолчанию `0.02`).
4. Ограничение 2D-тел (обнуление внеплоскостных скоростей).
5. Синхронизация физика → ECS (позиции, повороты, скорости; кинематика и грязные тела пропускаются).
6. Рассылка событий столкновений в колбэки скриптов `on_collision_enter/stay/exit`.

Солверы: `culverin` (на базе Jolt) по умолчанию, альтернативы `pybullet` и `physx`. Режимы: `single` (в процессе), `multi_threaded` (по умолчанию, отдельный процесс), `per_layer_process` (процессы по требованию на слой).

Подстраницы: Rigidbody, коллайдеры, CharacterController, джойнты, материалы и слои, солвер и многопоточность, продвинутые тела (плавучесть, soft body, PhysBone, мотор).

# Terrain-коллайдер

Heightfield-коллизия по данным террейна — дешевле и стабильнее меш-коллайдера для ландшафтов.

| Группа / поле инспектора | Смысл |
|---|---|
| Collision: Layer / Collision Mask | Фильтрация |
| Terrain: World Size | XZ-протяжённость heightfield |
| Terrain: Height Scale | Вертикальное преувеличение |
| Terrain: Resolution | Плотность высотных сэмплов |
| Terrain: Center | Локальный сдвиг |
| Is Trigger | События пересечения без контактного отклика |
| Material: Physic Material | Оверрайд ассетом `.zphysmat` |

Перегенерируйте коллайдер после скульпта террейна, иначе физическая поверхность разойдётся с видимой.

Связанное: террейн (раздел рендеринга), Rigidbody, Mesh-коллайдер.

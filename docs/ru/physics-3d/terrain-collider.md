# Terrain-коллайдер

Heightfield-коллизия по данным террейна: единственный sane способ сталкиваться с ландшафтами — гладкий высотный сэмплинг вместо миллионов треугольников.

| Группа / поле инспектора | Смысл |
|---|---|
| Collision: Layer / Collision Mask | Фильтрация |
| Terrain: World Size | XZ-протяжённость heightfield в юнитах |
| Terrain: Height Scale | Множитель вертикального преувеличения |
| Terrain: Resolution | Плотность высотных сэмплов (точность против памяти) |
| Terrain: Center | Локальный сдвиг |
| Is Trigger | События пересечения без контактного отклика |
| Material: Physic Material | Оверрайд ассетом `.zphysmat` |

Коллайдер обязан совпадать с визуальным террейном: тот же world size, тот же height scale, то же семейство resolution. Перегенерируйте после каждого скульпта — классический баг невидимых стен / парящего игрока это несвежий heightfield против отредактированного меша.

Гид разрешения: геймплейной точности нужны сэмплы плотнее мельчайшей трогаемой фичи (бордюры, колеи); дальние горы остаются грубыми. Избыточное разрешение жжёт память и время готовки за нулевой геймплейный выигрыш.

Персонажи идут по heightfield гладко, где меш-коллайдеры стучали бы на рёбрах треугольников — ещё причина всегда pair террейн с этим коллайдером, никогда с меш-.

Диагностика: тонет по колени — mismatch height scale; парит — несвежее поле, перегенерируйте; обрывы по краям — world size меньше визуала, расширьте; долгая загрузка — перебор resolution, делите пополам.

Связанное: террейн (раздел рендеринга), Rigidbody, Mesh-коллайдер, CharacterController (перекличка max slope).

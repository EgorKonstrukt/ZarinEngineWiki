# PhysBone

Динамика цепочек костей для волос, хвостов, плащей, антенн и висящего реквизита.

| Группа инспектора | Что покрывает |
|---|---|
| Transforms | Root Transform, Ignore Transforms, Ignore Other Phys Bones, Endpoint Position, Multi Child Type |
| Forces | Integration Type, Pull (+Curve), Spring (+Curve), Damping (+Curve) и дальнейшая настройка сил |
| Limits / Colliders | Limit Type, обработка Immobile, набор PhysBoneCollider |

Кривые по длине цепочки дают жёсткие корни с болтающимися концами. Коллайдеры отклоняют цепочку; формы см. в PhysBoneCollider.

Связанное: PhysBoneCollider, арматура, Skinned Mesh Renderer, заметки IK в анимации.

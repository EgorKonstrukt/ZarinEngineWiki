# Плавучесть Buoyancy

Плавающие тела для прудов, рек и океанов: корпуса вытесняют воду, волны качают, течения толкают.

| Группа / поле инспектора | Смысл |
|---|---|
| Buoyancy: Object Density | Плотность корпуса против воды — ниже плотности воды плавает |
| Override Volume | Ручной объём вытеснения, пропускает автовычисление |
| Water Density | Плотность жидкости (пресная/солёная/лавовая) |
| Hydro Drag / Hydro Angular Drag | Водное демпфирование движения и вращения |
| Flow Influence | Насколько течения толкают корпус |
| Options: Use Waves | Сэмплирование поверхности волн для качки |
| Options: Use Flow | Сэмплирование течений для дрейфа |
| Sample Resolution | Плотность проб по корпусу |
| Max Accel (x g) | Клапм стабильности водных сил |
| Debug Draw | Визуализация объёма и проб |

В пару — компонент окружения WaterVolume, маркирующий область жидкости, и поверхность Water для картинки: один компонент без определённой жидкости ничего не держит.

Порядок настройки: плотность пока ватерлиния не встанет (палуба в воде = слишком плотно), hydro drag пока остановка не станет весомой, волны для качки, течение для рек. Лёгкие катера хотят низкий drag и высокий max accel; баржи наоборот.

Sample resolution меняет точность на цену: высоко для длинных корпусов (пробы по длине ловят дифферент), низко для бочек. Debug Draw показывает пробы — мимо корпуса, и силы мимо.

Диагностика: тонет — плотность выше воды или недооценён объём, проверьте override; вибрирует — высок max accel или низко разрешение; игнорирует волны — выкл Use Waves или вне WaterVolume; вечный боковой дрейф — flow influence при несбалансированном поле течений.

Связанное: вода, заметки WaterVolume, Soft Body, Rigidbody (перекличка масс).

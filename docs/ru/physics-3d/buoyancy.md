# Плавучесть Buoyancy

Плавающие тела для прудов, рек и океанов.

| Группа / поле инспектора | Смысл |
|---|---|
| Buoyancy: Object Density | Плотность корпуса против воды |
| Override Volume | Ручной объём вытеснения |
| Water Density | Плотность жидкости |
| Hydro Drag / Hydro Angular Drag | Водное демпфирование |
| Flow Influence | Насколько течения толкают |
| Options: Use Waves / Use Flow | Сэмплирование поверхности и течений |
| Sample Resolution | Плотность проб по корпусу |
| Max Accel (x g) | Клапм стабильности |
| Debug Draw | Визуализация объёма |

В пару нужен компонент окружения WaterVolume, маркирующий область жидкости, и поверхность Water для картинки.

Связанное: вода, Soft Body, Rigidbody.

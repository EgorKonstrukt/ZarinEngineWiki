# Mesh-коллайдер

Коллизии из геометрии меша: статика точно, динамика — выпуклой аппроксимацией.

| Поле | Default | Смысл |
|---|---|---|
| center | начало | Локальный сдвиг |
| mesh_path | — | Исходный файл меша |
| collision_mode | AUTO | AUTO / MESH / CONVEX_HULL / BOX / SPHERE |
| max_vertices | 2000 | Бюджет упрощения |

Эффективный режим: AUTO превращается в MESH для статики и в CONVEX_HULL для динамики; явный MESH на динамике понижается до CONVEX_HULL. Тело динамическое при активном Rigidbody с положительной массой (кинематика тоже) и не-триггере.

Для всего движущегося предпочитайте примитивы и компаунды; меш-коллизии — для статичной геометрии уровня.

Связанное: MeshFilter, Rigidbody, заметки о компаунде в обзоре физики.

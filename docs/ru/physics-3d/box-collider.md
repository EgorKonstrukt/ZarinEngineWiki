# Box-коллайдер

Осевой бокс в локальном пространстве. Рабочая лошадка для ящиков, стен, полов, триггеров и кнопок — cheapest форма любого солвера, предпочитайте везде, где форма ложится.

| Группа / поле инспектора | Default | Смысл |
|---|---|---|
| Collision: Layer / Collision Mask | 0 / 0xFFFF | Кто с кем сталкивается |
| Shape: Center | начало | Локальный сдвиг от пивота |
| Shape: Size | единица | Локальные габариты, масштабируются трансформом |
| Is Trigger | выкл | События пересечения без контактного отклика |
| Material: Physic Material | — | Оверрайд ассетом `.zphysmat` |
| Инлайн трение / упругость | 0.6 / 0.0 | Без назначенного ассета |

На одной сущности несколько коллайдеров; примитивы box/sphere/capsule сливаются в одно составное тело — стол (крышка + 4 ноги) симулируется одним телом с пятью шейпами.

Процессы: полы — большой тонкий бокс, статика (без Rigidbody), трение 0.8+, чтобы персонажи не скользили; ящики — единичный бокс с Rigidbody 2–5, ничего не заморожено; триггеры — бокс с вкл `is_trigger`, скриптованный `on_collision_enter` для дверей, подборов и чекпоинтов; кнопки — тонкая триггер-пластина плюс визуальный меш, проседающий на enter.

Трюк компаунда: Г-лестница из 2–3 боксов бьёт любой меш-коллайдер по цене и стабильности. Держите боксы осевыми в локале; повёрнутые владельцы нормальны, скошенные (неоднородно shear) родители искажают форму — чините иерархию.

Диагностика: проваливается на скорости — туннелирование, кап скорости или ниже fixed dt; триггер молчит — mismatch масок или оба триггеры без скрипта-слушателя; неверный размер — забыт скейл трансформа, думайте `scaled_size` (локал × скейл).

Связанное: Rigidbody, физические материалы, слои коллизий, Mesh-коллайдер (когда боксы не ложатся), Box Collider 2D.

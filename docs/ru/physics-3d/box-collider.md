# Box-коллайдер

Осевой бокс в локальном пространстве. Рабочая лошадка для ящиков, стен, полов и триггеров.

| Группа / поле инспектора | Default | Смысл |
|---|---|---|
| Collision: Layer / Collision Mask | 0 / 0xFFFF | Фильтрация |
| Shape: Center | начало | Локальный сдвиг |
| Shape: Size | единица | Локальные габариты, масштабируются трансформом |
| Is Trigger | выкл | События пересечения без контактного отклика |
| Material: Physic Material | — | Оверрайд ассетом `.zphysmat` |
| Инлайн трение / упругость | 0.6 / 0.0 | Без ассета |

На одной сущности может быть несколько коллайдеров; примитивы сливаются в составное тело.

Связанное: Rigidbody, физические материалы, слои коллизий, Box Collider 2D.

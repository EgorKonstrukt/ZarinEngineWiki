# Глоссарий и FAQ

## Глоссарий

- **Сущность (Entity)** — объект сцены с UUID, именем, родителями/детьми, тегами, слоем, тумблером активности. Поведение — только от компонентов.
- **Компонент (Component)** — данные + хуки жизненного цикла (`on_awake/on_start/on_update/on_fixed_update/on_destroy/on_enable/on_disable`), автопоиск через `ComponentRegistry`.
- **ScriptComponent** — компонент-хост пользовательского `.py`-поведения: `script_path` + `script_fields` + `hot_reload`.
- **Класс поведения** — первый класс файла скрипта, объявляющий член жизненного цикла/столкновений/гизмо или `_inspector_buttons`; без базового класса, конструируется без аргументов.
- **Поле инспектора** — аннотированный атрибут класса, рисуемый виджетом; значения хранятся поинстансно в сцене.
- **Play** — режим запуска: скрипты грузятся, стреляют `on_awake`/`on_start`, идут покадровые апдейты. Методы гизмо работают и вне Play.
- **Hot-reload** — пересоздание инстанса по mtime во время Play с сохранением значений инспектора.
- **Fixed update** — колбэк на часах физики со стабильным `dt` (по умолчанию `0.02`); рендерный `dt` уже умножен на time scale.
- **Префаб (`.zpep`)** — сохранённое поддерево сущностей со стабильными GUID; инстансы перемаппливают GUID и хранят оверрайды.
- **Cython-компаньон** — соседний `.pyx`, собираемый в `cache/cython` при первом импорте и пересобираемый при новизне.
- **Time scale** — множитель рендерного `dt`; `dt` fixed-шага остаётся константой.

## FAQ

- **Скрипт молчит в Play?** Поле `Script` пусто или указывает на переехавший файл (`script_path` относительно корня проекта). Перевыберите; кнопка Check выдаёт ошибки `file:line`.
- **Нет `Vec3.rotate`?** Так и должно быть — вращение живёт в `Transform.rotate(Vec3 в градусах)`. У `Vec3` есть `dot/cross/length/normalized/lerp`, но не `rotate`.
- **Не импортируется `core.math3d`?** Импортируйте из `core.maths.math3d`. Кнопка Check подсказывает ровно это.
- **Правка в Play сбросила состояние?** Так задумано: состояние `__init__` сбрасывается при reload; настраиваемое держите в полях инспектора, кэши пересоздавайте в `on_awake`/`on_start`.
- **Мяч проваливается сквозь пол?** Нет коллайдера, включён `Is Trigger` без обработки контактов, либо `Is Kinematic` там, где нужно движение от солвера.
- **Нет звука?** Пустой/неразрешимый `clip_path`, нет `AudioListener` на камере, либо `play()` вызван без `AudioSystem` в headless-окружении.
- **Первый Play с `.pyx` тормозит?** Разовая нативная сборка в `cache/cython`; дальше переиспользуется. Кнопка Check валидирует `.pyx` без C-компилятора.

# Ассеты и импорт

Указатель раздела ассетов.

## Страницы

- Обзор — правило `.import`, дефолты типов, кэш.
- Импорт моделей — нативная библиотека, `MeshImportData`, скелет/блендшейпы.
- Текстуры — ключи `TextureImportSettings`.
- Настройки импорта — сайдкары меш/текстура/аудио.

## Проверено по

- `core/assets/importer/settings.py`, `core/assets/texture_import_settings.py`

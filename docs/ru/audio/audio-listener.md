# AudioListener

Уши сцены. Вешается на сущность камеры; трансформ слушателя определяет, что и откуда слышит игрок.

| Поле | Default | Диапазон инспектора | Смысл |
|---|---|---|---|
| doppler_factor | 1.0 | 0–10 | Сдвиг питча от относительного движения |
| speed_of_sound | 343.3 | 0.1–10000 | Эталон м/с для доплер-математики |

Поведение по кадрам, сверено с кодом:

- `on_start` один раз пушит оба значения в `AudioSystem`.
- `on_update` повторно пушит оба значения, затем ставит позицию слушателя из трансформа, ориентацию из forward/up трансформа, а скорость — конечной разностью позиций за `dt` (ноль на первом кадре).
- Оба поля сериализуются в сцену (`doppler_factor`, `speed_of_sound`) с теми же дефолтами при загрузке.

Рекомендации:

- Один активный слушатель на сцену. Два слушателя каждый кадр дерутся за состояние синглтона.
- Родительте слушателя к камере игрока: поворот влияет на панораму, движение — на доплер.
- Преувеличивайте `doppler_factor` (2–4) для аркадных пролётов; 1.0 для реализма. Подводные сцены опускают `speed_of_sound` к ~1480 для воды.
- Источники со `spatial_blend` 0 игнорируют позицию слушателя; источники с 1 панорамируются и затухают полностью.

Связанное: AudioSource, аудиосистема, камера.

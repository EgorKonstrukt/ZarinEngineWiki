# Аудиосистема

Сервисы движка за компонентами: ресурсы, декодирование, состояние источников и EFX-цепочка.

Модули (`core/audio`):

- `audio_system.AudioSystem` — синглтон: загрузка и кэширование клипов, асинхронные загрузки, сеттеры позиции/ориентации/скорости слушателя, доплер и скорость звука. Компоненты никогда не трогают OpenAL напрямую — вызывают сюда.
- `audio_system.AudioSourceManager` — синглтон: владеет нативными id источников и их состоянием — play, stop, pause, loop, громкость, питч, spatial blend, дистанции, кривые спада, формы зон и размеры боксов.
- `miniaudio_decoder.DecodedAudio` — бэкенд декодирования, превращающий `.wav` / `.mp3` / `.ogg` / `.flac` в PCM-буферы для загрузки в OpenAL.
- `audio_analyzer` — хелперы анализа (спектр и фолловеры уровня) для визуализаторов и beat-реактивных эффектов.
- `audio_efx` — обёртка расширения EFX для зон реверберации; `EFXError` сигналит отсутствие расширения, и движок откатывается на сухой выход.

Поток данных нового клипа: `AudioSource.play` → `play(...)` менеджера со всеми пространственными параметрами → система берёт клип из кэша или декодирует асинхронно → нативный источник конфигурируется (гейн, питч, зацикливание, позиция, спад) → компонент опрашивает состояние каждый кадр.

Дисциплина ресурсов: клипы кэшируются по пути — десять источников на одном файле декодируют один раз; длинные треки стримятся, а не прелоадятся целиком; освобождение последнего источника возвращает нативный id, а декодированный буфер остаётся в кэше для мгновенного реплея.

Поддержка гизмо: аудио-компоненты объявляют `audio` gizmo-проход с формами зон и кольцами дистанций — уровни миксуются визуально во вьюпорте.

Связанное: AudioSource, AudioListener, зона реверберации, Curve, профайлер (readout audio_ms).

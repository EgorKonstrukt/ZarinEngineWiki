# Аудиосистема

Сервисы движка за компонентами: ресурсы, декодирование, состояние источников и EFX-цепочка.

Модули (`core/audio`):

- `sys/system.py: AudioSystem` — синглтон: загрузка и кэширование клипов (`load_clip` / `load_clip_async` / `get_clip`, кэш по абс. пути + mtime `.import`), сеттеры позиции/ориентации/скорости слушателя, доплер и скорость звука, перечисление устройств. Компоненты никогда не трогают OpenAL напрямую — вызывают сюда.
- `sys/sources.py: AudioSourceManager` — синглтон: владеет нативными id источников и их состоянием — `play`, `stop`, `pause`, `stop_all`, громкость, питч, spatial blend, дистанции, кривые спада, формы зон и размеры боксов; лимит `audio.max_sources` (по умолч. 32).
- `sys/clip.py: AudioClip` — `load_from_file` (читает сайдкар `<клип>.import` `quality` 0–100 через `_resample`, пол 8000 Гц), `create_buffer`, `ensure_pcm` / `ensure_stereo_pcm`.
- `miniaudio_decoder.DecodedAudio` — бэкенд декодирования, превращающий `.wav` / `.wave` / `.mp3` / `.ogg` / `.vorbis` / `.flac` в PCM-буферы для загрузки в OpenAL.
- `audio_analyzer` — хелперы анализа (спектр и фолловеры уровня) для визуализаторов и beat-реактивных эффектов.
- `efx/` (`efx.py`, `filters.py`, `slots.py`) — обёртка расширения EFX для зон реверберации; `EFXError` сигналит отсутствие расширения, и движок откатывается на сухой выход.

Поток данных нового клипа: `AudioSource.play` → `play(...)` менеджера со всеми пространственными параметрами → система берёт клип из кэша (`load_clip`) или декодирует в пуле аудиопотока (`load_clip_async` с колбэком) → нативный источник конфигурируется (гейн, питч, зацикливание, позиция, спад) → компонент опрашивает состояние каждый кадр.

Дисциплина ресурсов: клипы полностью декодируются в PCM и кэшируются по абс. пути (инвалидация по mtime `.import`) — десять источников на одном файле декодируют один раз; освобождение последнего источника возвращает нативный id (`stop` / `stop_all`), а декодированный буфер остаётся в кэше для мгновенного реплея.

Поддержка гизмо: аудио-компоненты объявляют `audio` gizmo-проход с формами зон и кольцами дистанций — уровни миксуются визуально во вьюпорте.

Связанное: AudioSource, AudioListener, зона реверберации, Curve, профайлер (readout audio_ms).

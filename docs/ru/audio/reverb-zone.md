# Зона реверберации

Пространственная реверберация поверх OpenAL EFX: комнаты, залы, пещеры и тоннели, красящие каждый проходящий источник.

| Группа инспектора | Что покрывает |
|---|---|
| Zone | Min Distance (по умолч. 10.0), Max Distance (по умолч. 15.0) — радиусы полного эффекта и спада |
| Reverb Preset | Именованные стартовые точки для типовых пространств (по умолч. `Generic`; `Off` — обход, `User` — ручные параметры) |
| Room | Room level (по умолч. −1000), Room HF (по умолч. −100), Room LF (по умолч. 0) — баланс затухания низ/середина/верх |
| Decay | Decay Time (по умолч. 1.49), Decay HFRatio (по умолч. 0.83) — длина и яркость хвоста |
| Reflections | Уровень (по умолч. −2602) и задержка Reflections (по умолч. 0.007) — ранние отражения |
| Reverb | Уровень (по умолч. 200) и задержка Reverb (по умолч. 0.011) — позднее диффузное поле |
| Reference | HFReference (по умолч. 5000), LFReference (по умолч. 250) — частоты кроссовера |
| Rolloff | Room Rolloff Factor (по умолч. 0.0) — дистанционный отклик эффекта |
| Mix | Diffusion (по умолч. 100.0), Density (по умолч. 100.0) — плотность эха / модальная насыщенность |

Источник: `core/components/audio/reverb/component.py` (`_inspector_fields`, дефолты `__init__`, `serialize`/`deserialize` с миграцией legacy linear→мБ).

Рабочий процесс:

1. Добавьте компонент на пустую сущность в центре пространства.
2. Выберите ближайший пресет, Min Distance — на покрытие комнаты, Max Distance — на мягкий край.
3. Сначала Decay Time (комната ~0.3 с, зал ~1.5 с, пещера ~3 с), затем ранние отражения для хлопка, затем поздний уровень для wash.
4. Пройдите слушателем с зацикленным источником, проверьте вход и выход.

EFX-путь под guard: без расширения движок внутренне поднимает `EFXError` и продолжает сухо — смотрите консоль, если зона звучит плоско на отдельных машинах.

Связанное: AudioSource (spatial blend кормит посыл), AudioListener (позиция слушателя рулит маршрутизацией зон), аудиосистема (модуль EFX), туман (визуальный близнец для пещер).

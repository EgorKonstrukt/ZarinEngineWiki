# Аудио

Указатель раздела аудио.

## Страницы

- Обзор — тракт OpenAL: слушатель, источники, менеджер, система, EFX.
- AudioSource — клип, volume/pitch/loop, spatial blend, rolloff, фейды.
- AudioListener — doppler factor, speed of sound, пуш каждый кадр.
- Reverb Zone — пресеты EFX, room/decay/reflections, радиусы.
- System — `AudioSystem`, `AudioSourceManager`, miniaudio-декодер, анализатор, EFX.

## Проверено по

- `core/audio/sys/system.py`, `sys/sources.py`, `sys/clip.py`, `miniaudio_decoder.py`
- `core/components/audio/source/component.py`, `audio_listener.py`, `reverb/component.py`

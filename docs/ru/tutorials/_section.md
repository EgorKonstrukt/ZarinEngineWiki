# Уроки

Пошаговые руководства. Каждый шаг — реальное действие в редакторе или проверенный вызов API; каждый листинг — полный копируемый код.

- Обзор уроков — с чего начать, настройка проекта.
- Скрипты Rotator и Mover — первый Play: сущность, скрипт, настройка в инспекторе.
- Физическая сцена — Rigidbody, коллайдеры, силы, колбэки столкновений.
- GUI-меню, префабы, аудио, сборка — виджеты, переиспользование `.zpep`, AudioSource, `player.py`, сборка Nuitka.

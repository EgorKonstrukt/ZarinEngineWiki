# Поля инспектора и Range

Аннотированные атрибуты класса автоматически появляются в инспекторе, значения хранятся в сцене (`.zpes`). Дефолты уровня класса — начальные значения; правки инстанса их перекрывают, не трогая `.py`-файл. Приватные имена на `_` пропускаются, кроме специального `_inspector_buttons`.

```python
from enum import Enum
from typing import Annotated
from core.maths.math3d import Vec3
from core.foundation.curve import Curve


class Mode(Enum):
    IDLE = 0
    PATROL = 1


class Enemy:
    speed: Annotated[float, Range(0.0, 10.0)] = 5.0
    health: int = 100
    title: str = "grunt"
    active: bool = True
    offset: Vec3 = Vec3(0.0, 1.0, 0.0)
    mode: Mode = Mode.PATROL
    falloff: Curve = Curve()
    target: 'Entity' = None
    _inspector_buttons = [("explode", "Explode")]

    def explode(self):
        self.health = 0
```

| Аннотация | Виджет инспектора | Хранится как |
|---|---|---|
| `float` | Числовое поле | float |
| `int` | Целое поле | int |
| `bool` | Чекбокс | bool |
| `str` | Строка | строка |
| `Annotated[float, Range(min, max[, step])]` | Слайдер, шаг по умолчанию `0.01` | float, кламп к диапазону |
| `Annotated[int, Range(min, max)]` | Целый слайдер, шаг по умолчанию `1` | int, кламп к диапазону |
| `Vec2` / `Vec3` / `Vec4` | Векторные поля | float-компоненты |
| Подкласс `Enum` | Выпадающий список имён | значение enum |
| `'Entity'` | Пикер сущности | UUID; в скрипт приходит живой объект |
| `Curve` | Редактор кривой | набор кейфреймов |

Детали:

- `Range` — это `Range(min_value=0.0, max_value=1.0, step=None)`. Обычная последовательность `[min, max]` или `(min, max[, step])` в метаданных `Annotated` работает так же.
- Entity-пикер хранит UUID цели в сцене и резолвит живой объект перед каждым вызовом — безопасно при переименованиях, в отличие от поиска по имени.
- Ресурсные поля (меш, материал, текстура, аудио, префаб, сцена, физический материал) переиспользуют встроенные диалоги и фильтры: модели `*.obj *.fbx *.stl *.gltf *.glb *.usdz *.dae *.3ds *.blend`, материалы `*.zpem *.mat`, картинки `*.png *.jpg *.jpeg *.bmp *.tga *.tif *.tiff *.webp *.hdr *.exr *.dds *.svg`, аудио `*.wav *.mp3 *.ogg *.flac *.aiff *.m4a`, скрипты `*.py`, префабы `*.zpep`, сцены `*.zpes`, клипы и контроллеры анимации, физические материалы `*.zphysmat`.
- `_inspector_buttons = [(имя_метода, подпись), ...]` рисует кнопки, дёргающие метод на живом Play-инстансе (или редакторном вне Play) — удобно для тестовых триггеров вроде explode, reset, spawn.
- Шапка компонента показывает неизменяемое поле `Script` с отображаемым именем файла: клик показывает файл в Project, кнопка `...` открывает встроенный редактор. Смена файла перестраивает список полей; значения выживших имён сохраняются.
- Hot-reload накатывает значения инспектора на пересозданный инстанс — настройка переживает правки кода.

Рекомендация: крутилки дизайнеров (скорости, количества, тоглы) — в поля; внутренние кэши (`self._cache`, кулдауны) — обычными неаннотированными атрибутами из `on_awake`.

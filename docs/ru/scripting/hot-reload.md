# Горячая перезагрузка

Файл скрипта можно править прямо во время Play. Изменение подхватывается на следующем кадре: инстанс пересоздаётся, значения полей из инспектора сохраняются, `on_awake` / `on_start` вызываются заново. Состояние `__init__` сбрасывается — как рекомпиляция в Unity.

Детали поведения:

- Движок следит за временем изменения файла. Новый `mtime` вызывает перезагрузку перед следующим `on_update` / `on_fixed_update`.
- Значения полей, отредактированные в инспекторе, накатываются на новый инстанс, так что настройка переживает перезагрузку.
- Файл с синтаксической ошибкой отмечается в консоли как `Script '...' has N error(s):` со строками `файл:строка`. Предыдущая рабочая версия продолжает работать, пока файл не исправлен.
- Кнопка `Check` в редакторе скриптов проверяет без запуска Play: синтаксис плюс `core.*`-импорты, включая подсказку использовать `core.maths.math3d` вместо `core.math3d`.
- Перезагрузка управляется флагом `hot_reload` на `ScriptComponent` (по умолчанию `True`). Значение `False` замораживает инстанс на сессию.

Типичный цикл: нажать Play, подправить скорость или реакцию на кривую во внешнем редакторе, увидеть результат в запущенной игре на следующем кадре, сохранить настроенные значения в инспекторе, сохранить сцену.

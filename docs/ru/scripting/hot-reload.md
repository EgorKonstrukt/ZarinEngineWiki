# Горячая перезагрузка

Файл скрипта можно править прямо во время Play. Изменение подхватывается на следующем кадре: инстанс пересоздаётся, значения полей из инспектора сохраняются, `on_awake` / `on_start` вызываются заново. Состояние `__init__` сбрасывается — как рекомпиляция в Unity.

Конвейер перезагрузки:

1. Движок сравнивает время изменения файла перед каждым `on_update` / `on_fixed_update`. Новый `mtime` запускает перезагрузку.
2. Файл ревалидируется (те же проверки, что у кнопки Check). При ошибках в консоль пишется одно сводное сообщение `Script '...' has N error(s):` на версию файла, а предыдущий рабочий инстанс продолжает работать.
3. При успехе модуль перевыполняется с подставленным API, класс поведения резолвится заново, свежий инстанс конструируется.
4. Значения полей инспектора накатываются на новый инстанс, затем заново идут `on_awake` и `on_start`.

Что выживает: настроенные значения инспектора, обвязка компонента, иерархия сущностей. Что сбрасывается: всё назначенное в `__init__` или накопленное в колбэках (таймеры, кэши, спавн-хендлы) — перестраивайте в `on_awake`/`on_start`, если поведение должно продолжаться бесшовно.

Кнопка Check проверяет без Play в три стадии: парсинг синтаксиса с позициями `файл:строка`, резолвинг `core.*`-импортов (включая подсказку `core.maths.math3d` вместо `core.math3d`) и полное пробное выполнение, ловящее рантайм-ошибки импорта вроде циклических.

Управление: флаг `hot_reload` на `ScriptComponent` (по умолчанию `True`). Значение `False` замораживает инстанс на сессию — полезно при отладке нативного состояния или сравнении с фиксированным baseline.

Советы: держите Play запущенным и итерируйте ощущения (скорости, кривые, тайминги) во внешнем редакторе; настроенные значения инспектора переживают перезагрузки — сохраняйте сцену, когда ощущения верные. Для структурных рефакторингов (переименованные поля, новые кнопки) ждите один чистый цикл и перепроверьте инспектор.

Диагностика: изменения игнорируются — файл не сохранился (`mtime` тот же) или `hot_reload` выкл; старое поведение с ошибками — чините указанные `файл:строка`, живой остаётся последняя рабочая сборка; поля сбросились — аннотация переименована, у старого значения нет цели.

# ScriptComponent

`ScriptComponent` — движковая сторона пользовательских скриптов: загружает `.py`-файл, строит поля инспектора по классу, перенаправляет вызовы жизненного цикла и хранит значения полей в сцене.

Факты о компоненте:

- `script_path` хранится относительно корня проекта — сцены переносимы. Относительный путь, не резолвящийся напрямую, повторно ищется от корня проекта.
- `hot_reload` по умолчанию `True`.
- Несколько инстансов `ScriptComponent` могут жить на одной сущности.
- Шапка инспектора показывает отображаемое имя файла (базовое имя без расширения) с действием reveal и кнопкой редактора.

Резолвинг класса по шагам:

1. Если время изменения файла не менялось, используется кэшированный класс.
2. Папка скрипта добавляется в поиск импортов, чтобы находились соседние модули (включая Cython-сборки).
3. Файл проверяется на ошибки. При ошибках в консоль пишется одно сводное сообщение на версию файла, а старый инстанс сбрасывается; полей нет, пока файл не исправлен.
4. Модуль выполняется с подставленным API (`Input`, `KeyCode`, `Vec2/3/4`, `Curve`, `Range`, `Logger`).
5. Движок выбирает первый класс, определённый в этом файле (алфавитный порядок атрибутов), у которого есть хотя бы один колбэк жизненного цикла, колбэк столкновений, метод гизмо или `_inspector_buttons`. Класс инстанцируется без аргументов.
6. Привязка методов кэшируется для каждого имени, вместе с быстрыми флагами `on_update` / `on_fixed_update`; арности коллизий измеряются один раз через инспекцию сигнатуры.

Действие `Check` запускает ту же проверку, что и шаг 3, по требованию и показывает строки `файл:строка: сообщение`, так что сломанные скрипты диагностируются без нажатия Play.

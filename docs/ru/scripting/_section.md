# Скриптинг

Скрипты поведений, жизненный цикл, поля инспектора, API ввода и математики, hot-reload, Cython-модули, механика ScriptComponent, готовые примеры.

- Обзор — модель «`.py`-файл как ассет», сквозной процесс.
- Колбэки жизненного цикла — каждый метод, алиасы, сигнатуры, порядок вызовов.
- Поля инспектора и Range — аннотации в виджеты, Entity-пикер, кнопки.
- API ввода и математики — подставляемые имена, клавиши, оси, векторы, кривые.
- Горячая перезагрузка — правка скриптов во время Play.
- Cython в скриптах — компилируемые хелперы без ручных сборок.
- ScriptComponent — пути, флаги, резолвинг класса, Check.
- Примеры скриптов — готовые поведения.

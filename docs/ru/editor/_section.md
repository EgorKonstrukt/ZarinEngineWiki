# Руководство по редактору

Редактор ZarinEngine по докам — все факты прочитаны из исходников `editor/`.

- Главное окно — оболочка `EditorMainWindow`, меню, тулбар, проверенные хоткеи.
- Вьюпорт, камера, гизмо — миксины `SceneViewport`, облёт/орбита, привязка к сетке.
- Иерархия — дерево сущностей, DnD, операции с префабами, хуки коллаба.
- Инспектор — компоненты, пикеры, копирование/вставка значений, подредакторы аниматора.
- Панель проекта и ассеты — виды браузера, файловые операции с undo, визарды создания.
- Консоль и терминал — структурированный лог, вкладки Python REPL + PowerShell.
- Панель профайлера и история Undo — виды кадров, `UndoStack`, отчёты tracemalloc.
- Редакторы кривых, градиентов, цвета — диалоги, пресеты, семплирование.
- Мастер материалов и превью — живые GL-миниатюры материалов/моделей.
- Граф шейдеров — генерация GLSL из нод.
- Граф террейна и NodeGraphQt — GPU-запекание высот + превью на узел.
- Диалог сборки, менеджер проектов, настройки — диалоги поставки.
- Панели анимации, скриптов, префабов, меша, VCS — каталог доков-сателлитов.
- Доки коллаборации и MCP — живая сессия + мост для AI-агентов.

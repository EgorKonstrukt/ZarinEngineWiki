# Обзор физики 2D

Отдельный лёгкий 2D-конвейер со своими компонентами, симулируется тем же солвером, но с флагом 2D: внеплоскостные скорости (`vz`, наклоны) обнуляются каждый шаг, и тела остаются в плоскости.

Для скролл-шутеров, top-down игр и 2D-физики UI-плоскости, где полные 3D-тела избыточны. 2D-формы маппятся на солвер как плоские примитивы: `Box2D → box` с размером `[sx, sy, 1.0]`, `Circle2D → sphere`, сдвиги как `[ox, oy, 0]`.

Скрипты используют те же колбэки столкновений (`on_collision_enter/stay/exit`) и тот же фиксированный шаг (`dt = 0.02`).

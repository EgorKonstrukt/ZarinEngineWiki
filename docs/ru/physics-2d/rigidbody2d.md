# Rigidbody 2D

Плоская динамика для скролл-шутеров и top-down — та же форма API, что в 3D, в плоскости держит флаг солвера.

| Поле | Смысл |
|---|---|
| Mass | Вес; те же рекомендации отношений масс, что в 3D |
| Drag / Angular Drag | Плоское демпфирование |
| Gravity Scale | Локальный множитель гравитации (0 для top-down, 1 для платформеров) |
| Is Kinematic | Ведётся трансформом: движущиеся платформы, двери |
| Freeze Rotation | Лочит плоское вращение — персонажам почти всегда вкл |

Тот же API, что в 3D (`velocity`, `add_force`, `add_torque`, `add_impulse`). Каждый шаг солвер обнуляет внеплоскостные компоненты — top-down машинка никогда не клюёт в экран.

Паттерны: игрок — динамический с freeze rotation; движущаяся платформа — kinematic со скриптованным движением (едущие тела следуют через контакты); снаряд — динамический, gravity scale 0, убивается скриптом времени жизни; top-down машинка — динамическая с высоким angular drag для аркадных поворотов.

Диагностика: неконтролируемо вертится — выкл freeze rotation; парит в платформе — gravity scale 0 по ошибке; платформа роняет ездоков — платформа динамическая вместо kinematic.

Связанное: Box Collider 2D, Circle Collider 2D, Rigidbody (3D), слои коллизий.

# Box Collider 2D

Прямоугольник в плоскости: платформы, стены, ящики, хитбоксы и триггер-зоны.

| Группа / поле инспектора | Смысл |
|---|---|
| Collision: Layer / Collision Mask | Фильтрация |
| Shape: Offset | Сдвиг в плоскости `[ox, oy]` от пивота |
| Shape: Size | Габариты в плоскости |
| Is Trigger | События пересечения без контактного отклика |
| Material: Physic Material | Оверрайд ассетом `.zphysmat` |

Маппится на солвер как плоский бокс `[sx, sy, 1.0]` с центром `[ox, oy, 0]`. Комбинируйте с Rigidbody2D; не смешивайте 2D- и 3D-компоненты на одной сущности.

Паттерны: земля — широкий тонкий бокс, статика, высокое трение; односторонняя платформа — бокс на исключённом из маски игрока слое плюс верхний триггер, включающий коллизию сверху скриптом; ящики — мелкие боксы с динамическим Rigidbody2D 1–3; чекпоинты — высокие тонкие триггеры через трассу.

Тип pixel-perfect: размеры коллайдеров в целых дизайн-юнитах и консистентный pixel-to-unit, иначе визуал и коллизии разъедутся на больших координатах.

Диагностика: проваливается на быстрых — туннелирование, кап скорости или ниже fixed dt; триггер молчит — mismatch масок; края цепляют игрока — соседние боксы налегли, стыкуйте точно или сливайте в один.

Связанное: Rigidbody 2D, Circle Collider 2D, Box-коллайдер (3D), слои коллизий.

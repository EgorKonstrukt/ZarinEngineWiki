# Силовое поле частиц

Гнёт соседние системы частиц, не трогая их конфиги: зоны ветра, гравитационные колодцы, воронки вихрей, объёмы drag, восходящие потоки для листьев и угольков.

| Группа / поле инспектора | Смысл |
|---|---|
| Shape: Shape | Тип объёма поля (сфера/бокс-стиль) |
| Shape: Radius / Box Size | Радиус сферы или габариты бокса |
| Shape: Start Range | Дистанция начала спада |
| Force: Force X / Y / Z | Вектор направленной силы |
| Force: Intensity | Общий множитель силы |
| Force: Multiply by Distance | Масштабирование силы с дистанцией от центра |
| Drag, Gravity | Дополнительные демпфирование и гравитация внутри объёма |

Ставьте сущность поля так, чтобы объём накрывал эмиттер; частицы внутри подхватывают силу, вылетевшие хранят скорость. Складывайте несколько полей для curl-движения (swirl + lift + drag читается как торнадо).

Процессы: снос дыма костра — боковая сила со спадом, дым встаёт then дрейфует; туман водопада — гравитация вниз плюс распор наружу; магический вихрь — тангенциальная сила вокруг центра с подсосом внутрь; восходящий поток листьев — мягкая сила вверх над двором.

Поля складываются с собственной физикой системы аддитивно — при комбинации делите оба пополам, затем подтягивайте.

Диагностика: нет эффекта — объём мимо эмиттера, проверьте пересечение гизмо; жесть — intensity велик для масштаба масс, понизьте и поднимите drag; движение только в одну сторону — вектор одноосевой, добавьте компоненты.

Связанное: система частиц, зона ветра (ветер растительности), вода (ощущение течения), плавучесть (подводный близнец дрейфа).

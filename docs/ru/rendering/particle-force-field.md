# Силовое поле частиц

Искривляет соседние системы частиц: зоны ветра, гравитационные колодцы, вихри, объёмы drag.

| Группа / поле инспектора | Смысл |
|---|---|
| Shape: Shape | Тип объёма поля |
| Shape: Radius / Box Size | Радиус сферы или габариты бокса |
| Shape: Start Range | Дистанция начала спада |
| Force: Force X / Y / Z | Вектор направленной силы |
| Force: Intensity | Общая сила |
| Force: Multiply by Distance | Масштабирование с дистанцией |
| Drag, Gravity | Демпфирование и гравитация внутри объёма |

Ставьте сущность поля так, чтобы объём накрывал эмиттер. Несколько полей складываются в curl-подобное движение.

Связанное: система частиц, зона ветра (окружение), вода (течение).

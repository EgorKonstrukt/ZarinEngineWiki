# TextRenderer

Текст в мировом пространстве: подписи, вывески, отладочные оверлеи.

Рисуется со шрифтом, размером, цветом и выравниванием через внутренний шейдер `Text`. Следует за трансформом сущности как любой рендерер, так что текстовые панели поворачиваются и масштабируются с креплениями.

Для экранного UI-текста используйте виджеты GUI Label и соседние; этот компонент — для диегетического текста внутри 3D-мира.

Связанное: SpriteRenderer, SvgRenderer, контролы GUI.

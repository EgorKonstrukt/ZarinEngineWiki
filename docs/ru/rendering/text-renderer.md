# TextRenderer

Текст в мировом пространстве: плавающие подписи, вывески, табло, отладочные оверлеи, читаемые внутри 3D-вида.

Рисуется со шрифтом, размером, цветом и выравниванием через внутренний шейдер `Text`. Следует за трансформом как любой рендерер — текстовые панели поворачиваются и масштабируются с креплениями: табло кренится со столбом, неймплейт трекает NPC.

Процессы: неймплейты NPC — мелкий квад над головой с контрастным цветом, билбордится доворотом к камере из скрипта каждый кадр; вывески уровней — крупный статичный текст с unlit-подобным материалом для читаемости в любом свете; отладочные оверлеи — ридауты рядом с гизмо (позиции, состояния) под дебаг-флагом.

Держите строки короткими, размеры щедрыми: текст в мире конкурирует с деталями текстур, мелкие глифы алиасят. Для абзацев и rich text — виджеты GUI Label/TextEdit в скринспейсе.

Для экранного UI-текста используйте виджеты GUI; этот компонент — для диегетического текста в 3D-мире.

Диагностика: нечитаемо под углом — доворачивайте к камере или растите размер; выбелено — цвет борется с ключевым светом, переходите на светлое-по-тёмному; нет глифов — покрытие шрифта, меняйте ассет.

Связанное: SpriteRenderer, SvgRenderer, контролы GUI (Label, TextEdit), камеры.

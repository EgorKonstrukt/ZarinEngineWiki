# Глитч

Часть стека PostFX: выполняется после главной сцены в порядке компонентов. Построен на общей базе GraphicsEffect с тоглом и собственными полями инспектора.

## Как работает

Цифровые сбои вспышками: сдвиги слайсов, свопы каналов, шумовые удары с таймингами.

## Параметры

Сила вспышек, число слайсов, блочность, тайминги/триггер.

## Советы

Фидбэк урона, мини-игры взлома, глючащие голограммы. Триггерите из скриптов по попаданию.

## Цена

Дёшево в покое, средне во вспышках.

Связанное: [стек PostFX](../postfx.md), камеры (render scale), профайлер.

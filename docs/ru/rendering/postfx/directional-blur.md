# Направленное размытие

Часть стека PostFX: выполняется после главной сцены в порядке компонентов. Построен на общей базе GraphicsEffect с тоглом и собственными полями инспектора.

## Как работает

Размазывает пиксели вдоль одного экранного вектора — speed-линии без частиц.

## Параметры

Угол, длина, смещение центра.

## Советы

Следы дэша, варп-прыжки, дуги взмахов. В покое длина в ноль.

## Цена

Средне по длине. Только короткие вспышки.

Связанное: [стек PostFX](../postfx.md), камеры (render scale), профайлер.

# Моушн-блюр

Часть стека PostFX: выполняется после главной сцены в порядке компонентов. Построен на общей базе GraphicsEffect с тоглом и собственными полями инспектора.

## Как работает

Размазывает быстрые пиксели по экранной скорости ради ощущаемой плавности.

## Параметры

Ощущение затвора/сила, максимум сэмплов.

## Советы

Гонки, быстрые свинги камеры. Держите тонко, иначе мажется UI.

## Цена

Средне-высоко по числу сэмплов.

Связанное: [стек PostFX](../postfx.md), камеры (render scale), профайлер.

# Зерно плёнки

Часть стека PostFX: выполняется после главной сцены в порядке компонентов. Построен на общей базе GraphicsEffect с тоглом и собственными полями инспектора.

## Как работает

Анимированный мелкий шум по кадру, по умолчанию сильнее в тенях.

## Параметры

Зерно, количество, bias теней, скорость анимации.

## Советы

Киношный финиш поверх Bloom + Color Grading; поднимайте количество в тёмных зонах.

## Цена

Дёшево.

Связанное: [стек PostFX](../postfx.md), камеры (render scale), профайлер.

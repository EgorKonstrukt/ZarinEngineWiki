# Кувахара

Живописное уплощение областей, превращающее рендер в мазки масла. Построен на общей базе GraphicsEffect: тогл включения плюс собственные поля инспектора, выполняется в порядке компонентов после главной сцены.

Гид по цене: однопроходные цветовые операции дешёвые; многотапные и screen-space техники доминируют в пост-бюджете — профилируйте до сборки пачки.

Связанное: [стек PostFX](../postfx.md), камеры (render scale), профайлер.

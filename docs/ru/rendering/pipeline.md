# Конвейер ModernGL и Scene Renderer

Контексты:

- Игровые и редакторные вьюпорты создают контекст через `moderngl.create_context(standalone=False)` — общий контекст 4.6 core внутри Qt-поверхности.
- Офскрин-задачи (превью, воркеры террейна, compute) используют `moderngl.create_standalone_context(require=430)`.
- Шейдеры пишутся как `#version 430 core`. При ошибке компиляции загрузчик повторяет как `#version 330 core`, вырезая `layout(std430)`-буферы и принудительно отключая инстансинг/скиннинг — фолбэк совместимости, а не второй путь для поддержки.

Класс `Renderer` собран из миксинов: программы, uniform-переменные, фреймбуферы, сбор сцены, кэш геометрии, главный проход, проход теней, кубмапы, скиннинг, вода/воксели/эффекты объектов, пост-проход, гизмо/иконки/контуры, куллинг и статистика.

Кадр идёт по стадиям:

1. Сбор видимых элементов (фрустум-куллинг, маски слоёв).
2. Рендер карт теней (каскадные направленные, кубические точечные, спотовые) в глубинные цели.
3. Рендер главной сцены с материалами, светом (до 8 по умолчанию) и ambient.
4. Проходы воды, вокселей и эффектов объектов в свои цели.
5. Цепочка PostFX.
6. Редакторные оверлеи (сетка, гизмо, иконки, контуры, выделение) — только вьюпорты редактора.

Режимы рендера: `SHADED`, `SHADED_WIREFRAME`, `FLAT`. Цвет очистки по умолчанию тёмно-серый `[0.18, 0.18, 0.18]`, ambient по умолчанию холодный `[0.26, 0.28, 0.34]`.

# Арматура Armature

Контейнер иерархии костей, ведущий скинированные меши и цепочки PhysBone — скелетный ассет в сцене.

| Группа / поле инспектора | Смысл |
|---|---|
| Bone: Bone Name | Читаемое имя сустава (ретаргетинг матчится по имени) |
| Bone: Bone Index | Индекс на стороне солвера |
| Armature: Bone Count | Всего суставов |
| Armature: Root Bone | Корень иерархии; трансформ, двигающий весь риг |

Animator пишет позы в арматуру; SkinnedMeshRenderer и PhysBone их читают. Держите имена костей стабильными через реимпорты — ретаргетинг, оверрайды префабов и события анимации ключеваны именами.

Процесс: импорт рига → сверка Bone Count с DCC-ригом → Root Bone на бёдра/таз → привязка SkinnedMeshRenderer → навеска PhysBone-цепочек (волосы, пальто) на ту же арматуру → анимация.

Диагностика: частичная анимация — блудные кости вне count, проверьте DCC-экспорт; скользящие стопы — root motion не на том суставе, переназначьте Root Bone; спам оверрайдов префаба — кость переименована выше, верните имя.

Связанное: Skinned Mesh Renderer, PhysBone, клипы и Animator, блендшейпы.

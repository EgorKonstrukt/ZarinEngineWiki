# Skinned Mesh Renderer

Рисует скелетно-анимированные меши с GPU-скиннингом: персонажи, существа, анимированный реквизит.

| Группа / поле инспектора | Смысл |
|---|---|
| Mesh: Mesh | Источник анимированного меша с костными весами |
| Mesh: Source | Селектор источника привязки |
| Skinned Mesh Renderer: Materials | Слоты материалов, по одному на субмеш |
| Cast Shadows / Receive Shadows | Тоглы теней |
| Update When Offscreen | Скинить выкуленные меши (корректные тени и пробы) |

Костные веса приезжают с мешем из Assimp (позиции, нормали, UV, тангенты, цвета, веса — одним импортом). Система анимации (клипы, Animator, контроллеры) пишет позы в Armature каждый кадр; skinned-проход загружает костные матрицы один раз на меш и скинит вершины на GPU — цена CPU плоская независимо от вершин.

Процесс: импорт ригованного FBX, Armature (имена костей должны совпасть), SkinnedMeshRenderer с материалами, Animator с контроллером, проверка в Play — затем Update When Offscreen только для теневых толп.

Блендшейпы кладут морф-таргеты поверх скелета для лиц (см. страницу блендшейпов).

Диагностика: жёсткая T-поза — mismatch арматуры или нет аниматора; разлетающиеся вершины — проблема весов/нормализации импорта, реимпорт с тангентами; мёртвые тени — выкл Update When Offscreen на выкуленном кастере.

Связанное: арматура, блендшейпы, клипы и Animator, MeshRenderer (статика), PhysBone (физическая вторичка).

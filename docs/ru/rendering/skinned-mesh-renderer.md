# Skinned Mesh Renderer

Рисует скелетно-анимированные меши с GPU-скиннингом.

| Группа / поле инспектора | Смысл |
|---|---|
| Mesh: Mesh | Источник анимированного меша |
| Mesh: Source | Селектор источника привязки |
| Skinned Mesh Renderer: Materials | Слоты материалов, по одному на субмеш |
| Cast Shadows / Receive Shadows | Тоглы теней |
| Update When Offscreen | Скинить меши вне кадра (для теней и проб) |

Костные веса приезжают с мешем из Assimp; система анимации (клипы, Animator, контроллеры) пишет позы костей каждый кадр, skinned-проход загружает костные матрицы один раз на меш.

Связанное: арматура, блендшейпы, клипы и Animator, MeshRenderer (статичные меши).

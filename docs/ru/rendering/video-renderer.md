# VideoRenderer

Проигрывает видеоклипы на поверхности меша: экраны в мире, брифинг-стены, плоскости катсцен, анимированные билборды и фальшивые окна.

Проигрывание идёт через внутренний шейдер `Video` на видеодекодере движка — поверхность обычный меш, свет/тени/пост ложатся консистентно со сценой. Позиционируется трансформом; в пару — Projector с согласующимся светом для кино-ощущения.

Процессы: брифинг — стена-квад с клипом, приглушить свет зала, один спот на зрителей; стена CCTV — сетка мелких квадов со своими клипами; анимированные вывески — зацикленный клип вместо шейдерного скролла; плоскость катсцены — fullscreen-квад в камеру с letterbox-барами из GUI-панелей.

Для читаемых экранов в темноте тяните материал поверхности к emissive, чтобы картинка переживала низкий ambient. Следите за VRAM: несколько HD-клипов декодируются конкурентно — мало штук или скромные разрешения.

Диагностика: чёрный экран — бит путь или декодеру незнаком кодек, перекодируйте в поддерживаемый контейнер; статтер — упёрлись в декод, понизьте разрешение; рассинхрон со звуком — компонент только видео, ведите narration таймлайнами AudioSource.

Связанное: SpriteRenderer, материалы, Projector (кино-пара), AudioSource (звук-компаньон).

# VideoRenderer

Проигрывает видеоклипы на поверхности меша: экраны в мире, плоскости катсцен, анимированные билборды.

Проигрывание идёт через внутренний шейдер `Video` на видеодекодере движка. Позиционируется трансформом сущности; для читаемых экранов в тёмных сценах сочетайте с emissive-настройкой материала.

Связанное: SpriteRenderer, материалы, эффекты объектов.

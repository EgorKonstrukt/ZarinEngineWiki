# Скайбокс Skybox

Статичный HDRI-фон окружения с вкладом image-based освещения.

| Группа / поле инспектора | Смысл |
|---|---|
| HDRI Skybox: HDRI / EXR | Изображение окружения |
| HDRI Skybox: Show Background | Рисовать картинку как небо |
| HDRI Skybox: Affect Environment (IBL) | Освещать PBR-материалы картинкой |
| Image / Exposure (EV) / Intensity / Tint / Saturation | Контролы вида |
| Background Blur | Смягчение видимого неба |
| Flip Y, Orientation, Rotation Yaw/Pitch/Roll | Контролы маппинга |

Skybox — для запечённых окружений, Procedural Sky — для динамических суток. Согласуйте ambient с выбранным небом.

Связанное: процедурное небо, облака, атмосфера, направленный свет (процедурная связка).

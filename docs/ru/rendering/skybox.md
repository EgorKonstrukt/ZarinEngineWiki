# Скайбокс Skybox

Статичный HDRI-фон окружения с вкладом image-based освещения в PBR-материалы.

| Группа / поле инспектора | Смысл |
|---|---|
| HDRI Skybox: HDRI / EXR | Ассет изображения окружения |
| HDRI Skybox: Show Background | Рисовать картинку как видимое небо |
| HDRI Skybox: Affect Environment (IBL) | Освещать PBR-материалы картинкой |
| Image / Exposure (EV) / Intensity / Tint / Saturation | Контролы вида |
| Background Blur | Смягчение видимого неба (дешёвое ощущение глубины) |
| Flip Y, Orientation, Rotation Yaw/Pitch/Roll (deg) | Контролы маппинга |

Skybox — для запечённых, арт-директед окружений (интерьеры, стилизация, фотоплаты), Procedural Sky — для динамических суток. Согласуйте ambient с небом, иначе материалы уплывут.

Yaw-поворот анимирует иллюзию заката-рассвета на статичных HDRI; exposure едет по дневной кривой вместе с интенсивностью направленного.

Диагностика: чёрное небо — бит путь картинки или выкл Show Background; материалы темны под HDRI — выкл Affect Environment или низкая exposure; шов — mismatch ориентации/флипа с каптом, тогглите Flip Y.

Связанное: процедурное небо, облака, атмосфера, направленный свет, материалы (IBL-отклик).

# Облака

Облачный слой в объёмном стиле с покрытием, плотностью, дрейфом ветра и реакцией на солнце — небо с погодой, а не обои.

| Группа / поле инспектора | Смысл |
|---|---|
| Cloud: Cloud Material | Материал шейдинга на шейдерах `Clouds` / `CloudLayer` |
| Coverage / Density | Доля заполнения неба и толщина слоя |
| Wind Speed / Wind Direction | Вектор дрейфа |
| Height / Thickness / Noise Scale | Положение слоя и зерно клубов |
| Opacity / Shadow Strength | Вес вида и блокировка солнца |
| Fog Density / Height Falloff / Scattering | Смешивание в атмосферную дымку |

Затенённые облака темнят сцену согласованно с солнцем — пасмурное освещение бесплатно после настройки силы. Анимируйте ветер медленно (0.1–0.5) для живого неба; быстрые значения читаются как таймлапс.

Сочетается с фоном процедурного неба или скайбокса. Coverage около 1 с высокой плотностью — штормовой потолок; низкое покрытие с высоким scattering — хорошая погода точками.

Диагностика: невидимо — нулевые coverage или opacity; плоская белизна — density в максимуме без вариации noise scale; сцена не темнеет — нулевая shadow strength.

Связанное: процедурное небо, скайбокс, атмосфера, направленный свет.

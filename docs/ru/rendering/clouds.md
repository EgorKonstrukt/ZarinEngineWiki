# Облака

Облачный слой в объёмном стиле: покрытие, плотность, дрейф ветра, реакция на свет.

| Группа / поле инспектора | Смысл |
|---|---|
| Cloud: Cloud Material | Материал шейдинга (шейдеры `Clouds` / `CloudLayer`) |
| Coverage / Density | Заполнение неба и толщина |
| Wind Speed / Wind Direction | Дрейф |
| Height / Thickness / Noise Scale | Геометрия слоя |
| Opacity / Shadow Strength | Вид и блокировка солнца |
| Fog Density / Height Falloff / Scattering | Атмосферное смешивание |

Сочетается с фоном процедурного неба или скайбокса; затенённые облака темнят сцену согласованно с солнцем.

Связанное: процедурное небо, скайбокс, атмосфера.

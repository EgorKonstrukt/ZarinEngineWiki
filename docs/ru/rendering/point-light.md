# Точечный свет

Всенаправленная лампочка. Позиция из трансформа; затухание по `range`.

- Интенсивность в люменах, по умолчанию 1000. Ориентиры: свеча ~12.6, декоративный LED 100, настольная лампа 300, потолочный свет 800, лампа 100 Вт 1600, фонарь 15000.
- До 4 одновременных точечных карт теней (512 по умолчанию); включайте `cast_shadows` только где тени видны.
- Гизмо показывает сферу range.

Применение: лампы, взрывы, подборы, локальное свечение. Для больших интерьеров лучше несколько ярких точек, чем много тусклых.

Связанное: Light (база), тени, спот.

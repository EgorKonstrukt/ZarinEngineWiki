# Точечный свет

Всенаправленная лампочка во все стороны. Позиция из трансформа; яркость спадает по `range` и кривой дистанции.

- Интенсивность в люменах, по умолчанию 1000. Ориентиры: свеча ~12.6, декоративный LED 100, настольная лампа 300, потолочный свет 800, лампа 100 Вт 1600, фонарь 15000.
- До 4 одновременных точечных кубических карт (512 по умолчанию) — самый дорогой тип теней на свет из-за шести граней. Включайте `cast_shadows` только где тени читаются (hero-лампы, геймплейно важные света).
- Гизмо показывает сферу range; подгоняйте `range`, пока сфера не обнимет зону лампы — раздутые радиусы жгут бюджет и моют соседей.

Процессы: освещение комнат — одна затенённая точка на комнату на высоте потолка плюс незатенённые акценты; взрывы — короткий высокоинтенсивный пункт, гаснущий скриптом в ноль; подборы — малорадиусная пульсирующая точка (анимируйте intensity, не range, для дешёвого мерцания).

В физических единицах точка 1000 люмен рядом с солнцем 100000 люкс ведёт себя верно: солнце доминирует на улице, лампочка владеет интерьерами. Две затенённые точки в маленькой комнате удваивают цену кубов — лучше одна затенённая, остальные простые.

Связанное: Light (база), тени, спот, Emissive Pulse (визуальный близнец светильника).

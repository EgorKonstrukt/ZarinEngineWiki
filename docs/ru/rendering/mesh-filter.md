# MeshFilter

Отвечает *что* рисовать: ассет меша плюс имя субмеша внутри многосоставных файлов.

| Поле | Смысл |
|---|---|
| mesh_path | Файл модели: `.obj`, `.fbx`, `.stl`, `.gltf`, `.glb`, `.usdz`, `.dae`, `.blend`, `.3ds` и другие через Assimp C-FFI |
| mesh_name | Селектор субмеша внутри файла |

Импорт привозит вершины, нормали, UV, тангенты, цвета и веса скиннинга как numpy-массивы, кэширует в `Library`. Файловые настройки `.import` управляют масштабом, генерацией нормалей/тангентов и углом сглаживания, с OBJ-фолбэком для групп материалов.

Связанное: MeshRenderer, SkinnedMeshRenderer, MeshCollider, страница импорта моделей.

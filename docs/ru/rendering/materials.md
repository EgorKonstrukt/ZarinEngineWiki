# Материалы (.zpem)

Ассеты материалов — `.zpem` (и легаси `.mat`), оба JSON-документы `{name, shader_path, properties}`. Пустой `shader_path` откатывается на шейдер по умолчанию. Недостающие свойства добиваются из блока `Properties` шейдера при загрузке.

Маппинг текстурных uniform (выдержка): `albedo_texture → u_albedo_tex`, `normal → u_normal_tex`, `roughness → u_roughness_tex`, плюс прямые `_BaseMap`, `_NormalMap`, `_OcclusionMap`. Алиасы значений: `_BaseColor → u_albedo_color`, `_Metallic → u_metallic`, `_Smoothness → u_smoothness`, `_EmissionColor → u_emission`.

Дефолты при отрисовке: albedo белый `[1,1,1,1]`, metallic 0, smoothness 0.5, emission 0, белая текстура 1×1 на юните 0, реальные текстуры с юнита 1 с флагами `*_Active` / `u_use_*`.

Правило прозрачности: поверхность считается прозрачной, когда альфа падает ниже `0.999` или забинденная albedo-текстура содержит альфа-канал (определяется инспекцией изображения).

В редакторе материалы правятся через инспектор, мастер материалов и живое превью. Рантайм-правки свойств применяются сразу без реимпорта.

# Атмосфера Atmosphere

Физическое рассеяние атмосферы вокруг солнца и горизонта.

| Группа / поле инспектора | Смысл |
|---|---|
| Atmosphere: Enabled / Intensity | Мастер-выключатель и сила |
| Sun / Sun Intensity | Связанный источник-солнце |
| LUT Resolution | Плотность таблицы рассеяния |
| Ozone Factor / Aerosol Scale | Оттенок состава воздуха |
| Rayleigh Scale / Mie Anisotropy / Mie Albedo | Баланс синевы и дымки |
| Ground Albedo / Multiscatter | Аппроксимация отражённого света |
| Horizon Haze | Побележка под малыми углами |

Работает поверх процедурного неба; сцены с HDRI-скайбоксом обычно её выключают, чтобы не двоить тонировку.

Связанное: процедурное небо, направленный свет, облака.

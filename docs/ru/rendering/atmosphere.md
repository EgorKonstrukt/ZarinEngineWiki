# Атмосфера Atmosphere

Физическое рассеяние атмосферы вокруг солнца и горизонта — синий полдень, оранжевый закат, дымная даль.

| Группа / поле инспектора | Смысл |
|---|---|
| Atmosphere: Enabled / Intensity | Мастер-выключатель и сила |
| Sun / Sun Intensity | Ссылка на связанное солнце |
| LUT Resolution | Плотность таблицы рассеяния (качество против цены) |
| Ozone Factor / Aerosol Scale | Оттенок состава воздуха (синь против смога) |
| Rayleigh Scale / Mie Anisotropy / Mie Albedo | Баланс небесной сини и дымки вперёд |
| Ground Albedo / Multiscatter | Аппроксимация отражённого снизу света |
| Horizon Haze | Сила побележки под малыми углами |

Работает поверх процедурного неба; сцены с HDRI-скайбоксом обычно её выключают, чтобы не двоить тонировку (в фото воздух уже есть).

Процессы: альпийский полдень — высокий Rayleigh, низкий аэрозоль, хрустящая синь; пустынный закат — высокий Mie-лоб вперёд, тёплый ground albedo; смог-сити — аэрозоль вверх, озон сдвинут, сильная дымка горизонта.

LUT resolution — ручка цены: поднимайте пока не уйдёт полосатость, затем стоп — дальше заметит только профайлер.

Диагностика: фиолетовое небо — озон/аэрозоль за гранью правдоподобия, сбросьте к дефолтам; эффекта не видно — нулевая intensity или доминирует HDRI; белая стена горизонта — haze в максимуме, опускайте постепенно.

Связанное: процедурное небо, направленный свет, облака, туман.

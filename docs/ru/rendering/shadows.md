# Тени

Подсистема карт теней за каждым тоглом `cast_shadows`.

- Направленный: каскадная карта, по умолчанию 4 каскада с разрешениями 2048/1024/1024/512, дистанция 50.
- Точечный: кубические карты, 512 по умолчанию, до 4 одновременно.
- Спот: 1024 по умолчанию, до 4 одновременно.
- У каждого каскада/грани свои глубинные текстура и фреймбуфер; проход поддерживает GPU-инстансинг с плоским путём куллинга.
- Контролы bias: глобальные настройки плюс `area_shadow_bias` на свете (0.005 по умолчанию у area).

Порядок настройки: дистанция на игровую зону, минимальное приемлемое разрешение, затем bias до ухода акне без peter-panning. Профилируйте проход теней отдельно — он перерисовывает сцену на каскад/грань.

Связанное: Light (база), страницы направленного/точечного/спота/area, Projector.

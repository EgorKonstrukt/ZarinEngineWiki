# Обзор рендеринга

ZarinEngine рисует через ModernGL в контексте OpenGL 4.6 core profile. Вся математика движка работает в `numpy.float64`; понижение до `float32` происходит только при загрузке вершинных данных в GPU, что убирает дрожание координат в больших мирах.

Строительные блоки:

- Кастомные `.shader`-файлы с блоком `Properties { }` (в стиле Unity ShaderLab) плюс GLSL-код вершин и фрагментов.
- Ассеты материалов (`.zpem` / `.mat`, JSON), связывающие шейдер с конкретными значениями свойств.
- `MeshFilter` (какой меш) + `MeshRenderer` (как рисовать) на сущностях.
- Камеры (перспектива / ортография), свет (направленный / точечный / спот / area) с тенями.
- Рендереры спрайтов, SVG, текста и видео для 2D и плоскостей в мире.
- Системы частиц, скайбокс, туман, стек PostFX из 30+ эффектов, эффекты объектов, GPU-скиннинг.
- Редакторные проходы гизмо, иконок и контуров, которые никогда не попадают в игровое окно.

Подстраницы: конвейер и контексты, камеры, свет и тени, материалы, шейдеры, меш-рендеринг, спрайт/SVG/текст/видео, частицы, скайбокс и туман, PostFX, эффекты объектов, скиннинг, сплаты/рейтрейсинг/воксели, гизмо.

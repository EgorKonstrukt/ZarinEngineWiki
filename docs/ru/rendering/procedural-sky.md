# Процедурное небо

Динамическое небо суток: положение солнца, ночные звёзды, оттенок атмосферы — всё считается, без текстур.

| Группа инспектора | Что покрывает |
|---|---|
| Procedural Night Sky | Тогл Night Sky, Night Exposure |
| Stars | Density, Intensity, Scale, Twinkle, Twinkle Speed, Seed, Tint |
| Milky Way | Контролы полосы Млечного Пути |

Направленный свет с `procedural_sky_lighting` ведёт солнце: поворот света двигает диск и автоматически перебалансирует ambient.

Связанное: скайбокс, атмосфера, облака, направленный свет.

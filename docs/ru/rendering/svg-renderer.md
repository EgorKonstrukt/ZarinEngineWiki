# SvgRenderer

Чёткая векторная графика в мировом пространстве: иконки, вывески, оверлеи карт.

| Поле | Default | Смысл |
|---|---|---|
| svg_path | — | Векторный исходник |
| color | белый | Множитель оттенка |
| flip_x / flip_y | выкл / вкл | Зеркаляние |
| pixels_per_unit | 100 | Плотность растеризации |

SVG растеризуется в текстуру при загрузке, края остаются резкими при любом масштабе импорта. Увеличивайте `pixels_per_unit` для близких вывесок, уменьшайте для дальних иконок.

Связанное: SpriteRenderer, TextRenderer, материалы (маппинг текстур).

# Raytracing Renderer

Экспериментальный рейтрейс-компонент для исследований конвейера — не продакшн-путь (движок целится в OpenGL 4.6, без Vulkan/DX12).

| Поле | Смысл |
|---|---|
| Enabled | Мастер-выключатель |
| Compute Shader | Ядро рейтрейса |
| Resolution Scale | Множитель разрешения |
| Max Bounces | Глубина пути |
| Samples Per Pixel | Качество против шума |
| Accumulate Frames | Временная сходимость |
| Show Overlay / Heatmap (+ Mode / Scale) | Визуализация цены |

Полезен для референсных рендеров и изучения света; игры шипайте на стандартном меш-конвейере.

Связанное: Gaussian Splat Renderer, камеры, профайлер.

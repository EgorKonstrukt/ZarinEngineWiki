# SpriteRenderer

Текстурированный квад в мировом пространстве: билборды, подборы, декали, 2D-персонажи в 3D-сценах.

| Поле | Default | Смысл |
|---|---|---|
| texture_path | — | Картинка спрайта |
| color | белый | Множитель оттенка `[1,1,1,1]` |
| flip_x / flip_y | выкл / выкл | Зеркаляние |

Рисуется выделенным спрайтовым путём с поддержкой инстансинга; следует за трансформом сущности. Для полных UI-раскладок используйте GUI-систему.

Связанное: SvgRenderer, TextRenderer, VideoRenderer, обзор GUI.

# Спот

Конусный свет: фонарик, софит, фара. Направление из трансформа, конус из `spot_angle` / `spot_inner_angle`.

- Интенсивность в люменах, по умолчанию 1000 (та же шкала, что у Point Light).
- До 4 одновременных спотовых карт теней (1024 по умолчанию).
- Гизмо показывает конус с кольцом внутреннего угла.

Наводите поворотом трансформа; анимируйте `spot_angle` для зума и `intensity` для мерцания.

Связанное: Light (база), тени, Projector (текстурный конус).

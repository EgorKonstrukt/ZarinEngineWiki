# Спот

Конусный свет для фонариков, софитов, фар и оконных столбов. Направление из поворота трансформа, конус из `spot_angle` (внешний) и `spot_inner_angle` (яркое ядро).

- Интенсивность в люменах, по умолчанию 1000 — та же шкала, что у Point Light, светильники матчатся при смене типа.
- До 4 одновременных спотовых карт (1024 по умолчанию) — по одной грани, куда дешевле точечных кубов. Споты — экономный затенённый свет: предпочитайте везде, где приемлема направленность.
- Гизмо показывает конус с кольцом внутреннего угла; наводите поворотом сущности, сужайте `spot_angle` для театральных лучей, расширяйте для заливки.

Процессы: фонарик — спот родителем к камере с тенями и углом ~25°; сцена — несколько узких спотов с фермы с анимированными цветами; фары — два спота с range под тормозной путь; оконные столбы — широкоугольный спот сквозь раму плюс Projector для узора рамы.

Анимируйте `spot_angle` для зума и `intensity` для мерцания; оба — дешёвые uniform-обновления без перерегистрации.

Связанное: Light (база), тени, Projector (текстурный конус), точечный свет.

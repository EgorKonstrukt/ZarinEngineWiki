# Направленный свет

Солнце-подобный параллельный свет. Позиция задаёт только начало гизмо; направление берётся из поворота трансформа.

- Интенсивность в люксах, по умолчанию 100000 (прямое солнце). Ориентиры: полный день 15000, пасмурно 5000, восход 400, офис 500, сумерки 10, полная луна 0.2.
- `procedural_sky_lighting` связывает солнце с процедурным небом: поворот света двигает солнце и перебалансирует ambient.
- Тени — каскадная карта (по умолчанию 4 каскада, разрешения 2048/1024/1024/512, дистанция 50).

Типовая установка: одно направленное солнце с тенями как ключевой свет плюс ambient или небесная заливка.

Связанное: Light (база), тени, процедурное небо, атмосфера.

# Area-свет

Мягкий прямоугольный или дисковый излучатель для студий, окон и панелей.

- Интенсивность в нитах, по умолчанию 100. Ориентиры: SDR-монитор 200, офисная панель 500, пасмурное небо 2000, ясное небо 5000, LED-софтбокс 10000.
- `area_type` RECT или DISK, размер из `area_width` / `area_height`, `area_double_sided` для двустороннего излучения.
- Мягкость из `area_samples` (по умолчанию 6); `area_shadow_bias` 0.005 против акне.

Area-свет — самый дорогой тип: используйте как hero-источники, остальное добирайте точками и спотами.

Связанное: Light (база), тени, заметки Dynamic Cubemap в Skybox.

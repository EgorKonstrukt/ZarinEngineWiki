# Гизмо и иконки

Редакторные оверлейные проходы: линии/солиды гизмо, билборд-иконки, контуры выделения и сетка. Рисуются поверх всего во вьюпортах редактора и никогда не попадают в сборки — ноль рантайм-цены, полная постановочная польза.

Как подключаются компоненты:

- Каждый компонент объявляет `_gizmo_pass` (например `"light"`, `"camera"`, `"audio"`, `"script"`, проходы физики и навигации), маршрутизируя отрисовку в нужный батч.
- Опциональные файл `_icon`, `_gizmo_icon_color` и `_gizmo_icon_label` дают билборд-бейджи с буквой (Light `L`, Audio `A`, Projector `P` и другие) через проход иконок.
- Скрипты рисуют свои гизмо через `gizmo_lines()` / `gizmo_meshes()` — выполняются даже вне Play, идеальны для патрульных путей, радиусов спавна и конусов сенсоров.
- Встроенные рисуют свои формы: свет — фрустумы/объёмы, камеры — фрустумы, аудио-источники — формы зон (сфера/бокс) с кольцами дистанций, коллайдеры — каркасы, джойнты — якоря и оси, навигация — радиусы агентов.

Проходы за кулисами: проход иконок батчит билборды (один draw на много бейджей), проход контуров подсвечивает выделение, проход сетки рисует референсную сетку с оверлей-контролами, ширина линий по умолчанию 0.6667 для чёткой отладки.

Процесс: ставьте с вкл гизмо (конусы света, аудиозоны, триггер-боксы видны), для бьюти-скриншотов оверлеи выключайте. Кастомные гизмо скриптов держите дешёвыми — они работают каждый кадр редактора.

Диагностика: нет гизмо — выкл `_show_gizmo_icon` компонента или проход отфильтрован в опциях вьюпорта; гизмо скрипта несвежее — hot-reload пересоздал инстанс, переоткройте метод; каша — прячьте проходы по категориям в меню вьюпорта.

Связанное: гизмо-колбэки скриптинга, страницы Light/Projector/AudioSource/коллайдеров (их формы), вьюпорт (руководство по редактору).

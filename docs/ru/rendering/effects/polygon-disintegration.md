# Распад на полигоны

Эффект объекта через проход ObjectFx (в отличие от PostFX на весь кадр). Построен на общей базе ObjectEffect; скрипты ведут его, анимируя float прогресса/интенсивности.

## Как работает

Разбивает меш на летящие полигоны с попиксельной скоростью и затуханием.

## Параметры

Прогресс, скорость разлёта, затухание кусков.

## Советы

Эффектные разрушения, дезинтегрирующиеся враги, варп-уходы.

## Цена

Средне по числу кусков.

Связанное: [эффекты объектов](../effects.md), материалы, примеры скриптов.

# Распад на полигоны

Разбивает меш на летящие полигоны для эффектных разрушений. Построен на общей базе ObjectEffect и проходе ObjectFx: параметры прогресса и интенсивности выставлены наружу, скрипты ведут эффект, анимируя один float.

Связанное: [эффекты объектов](../effects.md), материалы, примеры скриптов.

# Воксельный реймарш

Эффект объекта через проход ObjectFx (в отличие от PostFX на весь кадр). Построен на общей базе ObjectEffect; скрипты ведут его, анимируя float прогресса/интенсивности.

## Как работает

Реймарш-рендер воксельных объёмов для плотных блочных сред с консистентным композитингом по глубине.

## Параметры

Плотность, число шагов, оттенок.

## Советы

Стилизованный дым, объёмная магия, блочные облака.

## Цена

Высоко по числу шагов. Сначала делите шаги.

Связанное: [эффекты объектов](../effects.md), материалы, примеры скриптов.

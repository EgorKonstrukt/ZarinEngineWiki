# Покачивание ветра

Мягкое общее покачивание вершин для травы, ткани и висящего реквизита. Построен на общей базе ObjectEffect и проходе ObjectFx: параметры прогресса и интенсивности выставлены наружу, скрипты ведут эффект, анимируя один float.

Связанное: [эффекты объектов](../effects.md), материалы, примеры скриптов.

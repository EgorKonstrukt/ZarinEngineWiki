# Диссолв

Выжигает поверхность по noise-порогу для спавнов, смертей и порталов. Построен на общей базе ObjectEffect и проходе ObjectFx: параметры прогресса и интенсивности выставлены наружу, скрипты ведут эффект, анимируя один float.

Связанное: [эффекты объектов](../effects.md), материалы, примеры скриптов.

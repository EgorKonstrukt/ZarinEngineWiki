# Диссолв

Эффект объекта через проход ObjectFx (в отличие от PostFX на весь кадр). Построен на общей базе ObjectEffect; скрипты ведут его, анимируя float прогресса/интенсивности.

## Как работает

Выжигает поверхность по анимированному шуму: пиксели за порогом discardятся с emissive-кромкой.

## Параметры

Прогресс 0→1, ширина/цвет кромки, масштаб шума.

## Советы

Спавны, смерти, порталы, выжигания. Ведите прогресс скриптом урона или таймера.

## Цена

Дёшево: один шумовой сэмпл плюс discard.

# Вода Water

Водные поверхности от тихих прудов до бесконечных океанов на шейдерах `Water` / `WaterSim`.

| Группа / поле инспектора | Смысл |
|---|---|
| Water: Water Shader | Выбор шейдера поверхности |
| Surface Type | Пути пресетов: гладь, река, океан |
| Infinite Ocean / Ocean Size | Тогл бесконечной плоскости и её масштаб |
| Waves | Контролы амплитуд/частот набора волн |
| Deep / Shallow / Foam / SSS / Horizon Color | Полный цветовой градиент от глубины к горизонту |
| Smoothness / Distortion / Detail Normal | Отклик поверхности и рефракционный воббл |

Плавающие тела — компонент Buoyancy; сама область жидкости маркируется компонентом окружения WaterVolume; каустика и подводный рендер — парными внутренними шейдерами.

Процессы: пруд — малая плоскость, пресет глади, высокая smoothness для зеркальных отражений скайбокса; река — вытянутая плоскость, направленные волны, пена у берегов; океан — infinite вкл, размер под far plane, цвет горизонта сплавлен с туманом.

Пена ложится по глубине (полоса shallow) — согласуйте шельф террейна с shallow-диапазоном, иначе пена плавает неверно. Distortion продаёт рефракцию; перебор — и текст за водой нечитаем.

Диагностика: чёрная вода — биты шейдер или источник отражений, проверьте скайбокс/ambient; нет плавучести — нет WaterVolume, одна поверхность тел не держит; пена везде — shallow-диапазон шире шельфа.

Связанное: плавучесть, скайбокс (отражения), туман, PostFX (подводный грейдинг-близнец).

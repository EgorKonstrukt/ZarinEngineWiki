# Вода Water

Водные поверхности от тихих прудов до бесконечных океанов.

| Группа / поле инспектора | Смысл |
|---|---|
| Water: Water Shader | Шейдер поверхности (`Water` / `WaterSim`) |
| Surface Type | Путь пресетов: гладь, река, океан |
| Infinite Ocean / Ocean Size | Бесконечная плоскость и её масштаб |
| Waves | Контролы набора волн |
| Deep / Shallow / Foam / SSS / Horizon Color | Цветовой градиент |
| Smoothness / Distortion / Detail Normal | Отклик поверхности |

Плавающие тела — компонент Buoyancy; сама область жидкости маркируется компонентом окружения WaterVolume. Каустика и подводный рендер — парными внутренними шейдерами.

Связанное: плавучесть, заметки WaterVolume, скайбокс (отражения), туман.

# Проектор Projector

Проецирует текстуру из фрустума: слайд-проектор, фальшивый оконный свет, луч граффити, метатель логотипов.

| Группа / поле инспектора | Default | Смысл |
|---|---|---|
| Texture: texture_path | — | Проецируемое изображение (png/jpg/jpeg) |
| Texture: color | белый | Множитель оттенка |
| Texture: intensity | 1.0 | Яркость, 0–1000 |
| Projection: range | 10.0 | Дистанция броска |
| Projection: spot_angle | 30° | Угол фрустума, 1–179 |
| Projection: aspect_ratio | 1.0 | Ширина/высота фрустума |
| Projection: near_plane / far_plane | 0.1 / 100 | Срез глубины броска |
| Options: flip_x / flip_y | выкл / вкл | Зеркаляние картинки |
| Options: cast_shadows | вкл | Окклюдеры блокируют проекцию |

Гизмо рисует конус с корректным прямоугольником основания — кадрируйте целевую поверхность визуально, затем точно подгоняйте угол и range. Наводится трансформом ровно как Spot Light; срез (near/far) обрезает бросок, и он не протекает сквозь задние стены.

Процессы: кино — сущность проектора за зрителями в белый экран в духе VideoRenderer; фальшивые окна — яркий проектор с текстурой рамы плюс мягкий спот для spill; движущиеся декали — анимированного offset нет, меняйте `texture_path` из скрипта для слайд-шоу.

Цена: один лишний набор фрустум-сэмплов на проектор; затенённые идут в проход projector shadows. Держите число малым (1–3) и range tight.

Диагностика: зеркальная картинка — тоглы flip_x/flip_y; проекция сквозь стены — подтяните far_plane; выбелено — intensity спорит с ключевым, поднимите или приглушите сцену.

Связанное: Spot Light, тени (проход projector shadows), VideoRenderer (поверхности экранов), TextRenderer (альтернатива статичных слайдов).

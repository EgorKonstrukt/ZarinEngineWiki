# Gaussian Splat Renderer

Рисует Gaussian-splat захваты — сцены в стиле фотограмметрии как сортированные точечные объёмы.

| Поле | Смысл |
|---|---|
| Splat Path | Файл захвата |
| SH Degree | Уровень качества сферических гармоник |
| Opacity Cutoff | Порог прозрачности |

Сплаты сортируются каждый кадр выделенным быстрым путём, разделяют видимость и статистику с мешами, но обходят часть цепочки PostFX — проверяйте градуированный вид в игровом окне.

Коллизии для splat-объёмов — через GS Volume Collider.

Связанное: GS Volume Collider, материалы, камеры.

# Камера редактора

Камера монтажа сцены. Никогда не входит в сборку; только ведет вьюпорты редактора с орбитой, панорамированием и полётом.

| Поле инспектора | Default | Смысл |
|---|---|---|
| Move Speed | 5 | Скорость полёта/орбиты |
| Rotate Speed | — | Скорость yaw/pitch |
| Zoom Speed | — | Скорость наезда |
| Pan Speed | — | Скорость панорамирования |
| Damping | — | Сглаживание движения |
| Acceleration | — | Разгон скорости |

Управление: WASD/QE — полёт, драги правой/средней кнопок, Alt+LMB — орбита, быстрый режим ×3.

Связанное: Camera (рантайм-виды), страница вьюпорта в руководстве по редактору.

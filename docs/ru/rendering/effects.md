# Эффекты объектов

Эффекты объектов анимируют одиночный объект во времени через проход ObjectFx (в отличие от PostFX, обрабатывающего весь кадр). Каждый — компонент ObjectEffect, ведомый float прогресса/интенсивности. По странице на эффект:

- [Диссолв](effects/dissolve.md)
- [Пульс эмиссии](effects/emissive-pulse.md)
- [Иней](effects/frost.md)
- [Глитч объекта](effects/glitch.md)
- [Голограмма](effects/hologram.md)
- [Распад на полигоны](effects/polygon-disintegration.md)
- [Рост шипов](effects/spike-growth.md)
- [Ветер деревьев](effects/tree-wind.md)
- [Вокселизация](effects/voxelize.md)
- [Воксельный реймарш](effects/voxel-raymarch.md)
- [Покачивание ветра](effects/wind-sway.md)

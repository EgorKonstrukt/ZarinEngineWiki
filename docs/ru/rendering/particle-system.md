# Система частиц

CPU-симуляция с GPU-отрисовкой для искр, дыма, магии, обломков, погоды и ambient-пыли. Для тяжёлых систем, топящих CPU, есть GPU-путь проигрывания (шейдер `ParticleGpu`).

| Группа инспектора | Что покрывает |
|---|---|
| Emission | Duration, Looping, Prewarm, Start Delay — когда и сколько работает эмиттер |
| Start | Start Lifetime (Min/Max), Start Speed (Min/Max), Start Size (Min/Max) и другое начальное состояние частицы |
| Appearance | Размер и цвет по жизни, текстура |
| Physics | Гравитация, drag, реакция на коллизии |

Система рисует гизмо-представление прямо во вьюпорте — форма эмиттера, конус направления и range читаются без Play. Крутите rate эмиссии и смотрите, как меняется плотность гизмо.

Процессы: костёр — короткая жизнь, скорость вверх, градиент оранжевый-в-прозрачность, зацикливание с prewarm, чтобы стартовал полным; взрыв — одиночный burst (looping выкл) с широким разбросом скоростей плюс вспышка Point Light; дождь — огромный count, тонкая вытянутая текстура, GPU-путь, без коллизий; магический след — эмиттер родителем к снаряду, малый count, аддитивный-подобный материал.

Вспышки и циклы запускаются из скриптов в рантайме через API компонента; ведите интенсивность от геймплея (обороты двигателя → rate выхлопа).

Правила производительности: лучше несколько крупных GPU-систем, чем много мелких CPU; одна текстура на системы; следите за overdraw — большие мягкие прозрачные квады обычный убийца fill-rate; гасите эмиттеры вне кадра дистанционным куллингом или ручным enable.

Диагностика: невидимо — потеряна текстура, нулевой размер или нулевая жизнь; комкование в начале — нулевая скорость или ненастроенное направление; сработал раз и встал — выкл looping на ambient-эффекте; в редакторе видно, в игре нет — маска слоёв исключила игровую камеру.

Связанное: силовое поле частиц, эффекты объектов (спавн-вспышки), материалы (текстуры частиц), Point Light (вспышка взрыва).

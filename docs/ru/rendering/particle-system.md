# Система частиц

CPU-симуляция с GPU-отрисовкой: искры, дым, магия, обломки. Для тяжёлых систем есть GPU-путь проигрывания (шейдер `ParticleGpu`).

| Группа инспектора | Что покрывает |
|---|---|
| Emission | Duration, Looping, Prewarm, Start Delay |
| Start | Start Lifetime (Min/Max), Start Speed (Min/Max), Start Size (Min/Max) и другое начальное состояние |

Эмиссия, внешний вид (размер и цвет по жизни, текстура) и физика (гравитация, drag) настраиваются в инспекторе. Система рисует гизмо-представление прямо во вьюпорте — форма и направление видны без Play. Вспышки и циклы запускаются из скриптов в рантайме.

Производительность: лучше несколько крупных GPU-систем, чем много мелких CPU; переиспользуйте одну текстуру; следите за overdraw от больших мягких прозрачных квадов.

Связанное: силовое поле частиц, эффекты объектов, материалы (текстуры частиц).

# Свет Light (база)

Базовый компонент всего света. Конкретный тип задаётся подклассом на той же сущности: Directional, Point, Spot или Area. Общие поля живут здесь один раз.

| Поле | Default | Смысл |
|---|---|---|
| color | белый | Оттенок, множит каждый вклад |
| intensity | 100000.0 | Физические единицы — люксы, люмены или ниты по подтипу |
| cast_shadows | вкл | Писать в карты теней; главный переключатель цены света |
| range | 10.0 | Дистанция затухания point/spot/area (направленный игнорирует) |
| spot_angle / spot_inner_angle | 30 / 20 | Внешний/внутренний конус спота, градусы |
| area_type | RECT | Форма излучения RECT или DISK для area |
| area_width / area_height | 1×1 | Размер излучающей поверхности |
| area_double_sided | выкл | Излучение с двух сторон |
| area_samples | 6 | Число сэмплов мягких теней |
| area_shadow_bias | 0.005 | Сдвиг против акне теней |

Как доходит до шейдера: сборщик сцены пакует до 8 светов в uniform-массивы (тип, позиция, направление, цвет, интенсивность, range, углы спота, размер area) плюс ambient. Сверхлимитные выкуливаются по приоритету — держите hero-света мало, остальное незaтенённая заливка.

Весь свет рисует гизмо-хелперы (стрелки направления, сферы range, конусы, area-квады) — свет ставится визуально.

Процесс: сначала ключевой (обычно один затенённый направленный), затем заливные точки/споты без теней, в конце контровой или area-акцент. Согласуйте интенсивности со шкалой — солнце 100000 люкс рядом с точкой 1.0 читается верно; два солнца по 100000 дерутся.

Диагностика: темно — низкий ambient без заливки; пересвет — два hero перекрылись, делите один пополам; нет теней — выкл cast_shadows, вне дистанции, или превышен бюджет 4+4.

Связанное: страницы направленного/точечного/спота/area, Projector, тени, скайбокс и атмосфера.

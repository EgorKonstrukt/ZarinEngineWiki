# Свет Light (база)

Базовый компонент всего света. Конкретный тип задаётся компонентом-подклассом на той же сущности.

| Поле | Default | Смысл |
|---|---|---|
| color | белый | Оттенок света |
| intensity | 100000.0 | Физические единицы, см. страницы подтипов |
| cast_shadows | вкл | Писать в карты теней |
| range | 10.0 | Дистанция затухания point/spot/area |
| spot_angle / spot_inner_angle | 30 / 20 | Конус спота, градусы |
| area_type | RECT | RECT или DISK для area |
| area_width / area_height | 1×1 | Размер излучающей поверхности |
| area_double_sided | выкл | Излучение с двух сторон |
| area_samples | 6 | Сэмплы мягких теней |
| area_shadow_bias | 0.005 | Сдвиг против акне теней |

Подтипы: направленный (люксы), точечный (люмены), спот (люмены), area (ниты), плюс компонент Projector для текстурной проекции. Весь свет рисует гизмо-хелперы во вьюпорте.

Связанное: тени, скайбокс и процедурное небо, Fog и God Rays из PostFX.

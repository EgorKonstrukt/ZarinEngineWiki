# MeshRenderer

Отвечает *как* рисовать меш из `MeshFilter`.

| Поле | Default | Смысл |
|---|---|---|
| materials | — | Слоты материалов (`{path}` каждый, например `.zpem`), по одному на субмеш |
| cast_shadows | вкл | Писать в карты теней |
| receive_shadows | вкл | Читать карты теней |
| uv_scale / uv_offset | (1,1) / (0,0) | Тайлинг и сдвиг |
| uv_scale_by_transform | выкл | Выводить тайлинг из трансформа |
| sprite_texture | — | Опциональный оверрайд-билборд |
| dynamic_reflections | выкл | Обновлять отражения окружения каждый кадр |

Геометрия загружается один раз через кэш геометрии; покадровая цена — один draw на видимый субмеш. Для анимированных мешей — SkinnedMeshRenderer; для моделирования в редакторе — ProBuilder-компонент.

Связанное: MeshFilter, материалы, шейдеры, тени.

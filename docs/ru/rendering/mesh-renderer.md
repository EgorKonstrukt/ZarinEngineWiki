# MeshRenderer

Отвечает *как* рисовать меш из `MeshFilter`: слоты материалов, участие в тенях, UV-трансформы.

| Поле | Default | Смысл |
|---|---|---|
| materials | — | Слоты материалов (`{path}` каждый, например `.zpem`), по одному на субмеш по порядку |
| cast_shadows | вкл | Писать в карты теней |
| receive_shadows | вкл | Читать карты теней в главном проходе |
| uv_scale / uv_offset | (1,1) / (0,0) | Тайлинг и сдвиг через UV-оверрайд шейдера |
| uv_scale_by_transform | выкл | Выводить тайлинг из скейла трансформа (полы, стены) |
| sprite_texture | — | Опциональный оверрайд-билборд |
| dynamic_reflections | выкл | Обновлять отражения окружения каждый кадр вместо по требованию |

Порядок и цена: один draw call на видимый субмеш после фрустум-куллинга; прозрачные материалы сортируются в прозрачный бакет по глубине. Кастеры рисуются в каждую накрывающую карту теней — высокополигональный hero с вкл cast кратно удорожает тени: выключайте cast мелкому реквизиту без читаемых теней.

UV-процесс: тайлинг кирпича/бетона через uv_scale (4,4) вместо дублирования геометрии; скролл анимацией uv_offset из скрипта (конвейеры, водные горки); world-aligned отделка через uv_scale_by_transform на архитектуре.

Для анимированных — SkinnedMeshRenderer; для блокаута в редакторе — ProBuilder-компонент `probuilder_mesh`; для коллизий — MeshCollider на том же пути фильтра.

Диагностика: меш невидим — бит путь фильтра или все материалы потеряны; не тот материал субмеша — рассинхрон порядка слотов, переупорядочьте; нет теней — cast вкл, но свет вне дистанции, или receive выкл на земле; мерцание UV — неоднородный отрицательный скейл, чините трансформ.

Связанное: MeshFilter, материалы, шейдеры (UV-оверрайд uniforms), тени, SkinnedMeshRenderer.

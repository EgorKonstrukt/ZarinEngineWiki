# Интерфейс GUI

Указатель раздела интерфейсной системы.

## Страницы

- Обзор — канвас, `GuiApi`, реестр виджетов.
- Канвас — `GuiCanvas`, разрешение, save/load.
- Контролы — Button, Toggle, RadioButton, ToolButton, Label, TextInput, PlainText, TextEdit, Slider, ScrollBar, ProgressBar, Dial, SpinBox, DoubleSpinBox, ListWidget, TreeWidget, TableWidget, Dropdown, FontCombo, Image, HtmlView, Calendar, LCDNumber, ChartPlotter.
- Контейнеры — Panel, GroupBox, TabWidget, StackedWidget, Splitter, ScrollPanel, MdiSubWindow, MdiArea, ToolBox.
- Раскладка и события — якоря 0–11, horizontal/vertical/grid, Fusion, Qt-сигналы + `GuiEvent`.

- `core/gui/wid/__init__.py`, `core/gui/canvasp/canvas.py`, `core/gui/api.py`
